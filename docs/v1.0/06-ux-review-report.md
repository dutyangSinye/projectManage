# 芯烨工时管理系统 UX 走查报告

> 版本：v1.0.1 ｜ 日期：2026-08-25 ｜ 状态：MVP 走查完成

## 已通过

- 登录后首屏直接呈现周期进度、草稿数量和待处理事项。
- 新增工时只展示可填报项目，保存后能回到个人工时列表。
- 提交前先预览数量、单位和审批人，避免直接触发审批。
- 审批中的明细明确展示只读状态和审批实例号。
- 报表明确展示统计范围，管理页面与个人页面入口分开。
- 移动端隐藏侧栏、保留核心操作和可横向滚动表格。

## 遗留事项

1. 接入真实飞书 OAuth 后需要补充首次登录授权和失效重登体验。
2. 接入真实审批回调后需要补充驳回意见、撤回和回调失败重试交互。
3. 管理员配置入口目前以状态展示为主，下一迭代补充字段映射编辑和同步任务详情。

## 结论

MVP 主链路可用于本地验收；真实飞书能力接入前，不应作为生产系统上线。
