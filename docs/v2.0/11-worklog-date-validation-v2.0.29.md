# 工时日期校验改造

> 版本：v2.0.29 ｜ 日期：2026-08-27 ｜ 状态：已完成，待业务 UAT

## 规则

- 开始日期不能晚于结束日期。
- 开始日期和结束日期必须属于同一个自然月，禁止跨月填报。
- 同一人员所有项目的日期区间按闭区间判断，任意交集都视为重叠；同一天填不同项目也不允许。
- 编辑工时会排除当前记录自身；草稿、驳回、审批中、已通过和已锁定记录均参与重叠判断。

## 校验入口

- 新增工时：创建接口校验。
- 保存草稿/修改工时：编辑接口校验。
- 草稿重新提交：提交接口再次校验，避免保存后被其他工时占用。
- 管理员修改工时：管理员接口同样校验。
- 前端在提交前做日期格式、倒置和跨月即时提示；区间重叠由后端返回最终结果。

## 错误码

| 错误码 | HTTP | 页面提示 |
|---|---:|---|
| `DATE_RANGE_INVALID` | 400 | 工时开始日期不能晚于结束日期 |
| `DATE_RANGE_CROSSES_MONTH` | 400 | 工时开始日期和结束日期不能跨月 |
| `WORKLOG_DATE_OVERLAP` | 409 | 该人员已有日期重叠的工时 |
