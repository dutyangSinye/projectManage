## v2.0.27 工时审批 TAB 验证

- 桌面端导航和页面标题统一显示“工时审批”；“待我审批”和“已审批” TAB 可正常切换并显示数量徽标。
- 樊公海身份下待审批列表显示 1 条任务，已审批列表显示 4 条历史任务，历史结果同时覆盖已通过和已驳回。
- 移动端 `390×844` 下 TAB、列表和空态均可见，`body.scrollWidth` 与 `window.innerWidth` 均为 390，无整体横向溢出。
- 普通身份的已审批列表为空；后端接口按当前审批人隔离数据，未发现跨用户读取。

结论：工时审批双 TAB 的桌面端、移动端和权限边界验证通过。
