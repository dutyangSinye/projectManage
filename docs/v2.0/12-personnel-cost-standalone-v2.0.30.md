# 人员成本独立功能

> 版本：v2.0.30 ｜ 日期：2026-08-27 ｜ 状态：已完成，待业务 UAT

## 功能调整

- “人员成本”从“集成与通知”拆为独立的管理员菜单和页面。
- 组织同步仍位于“集成与通知”，人员成本页面只负责成本维护。
- 支持按部门、人员筛选，并支持 10、20、50 和 1-200 条自定义分页。
- 使用紧凑表格维护人员、部门和单天成本；保存成功后保留当前筛选和分页位置。
- 桌面侧边栏仅系统管理员显示；移动端通过“工时管理”页面的快捷入口访问。

## API

`GET /api/v1/admin/personnel-costs` 支持 `page`、`page_size`、`department_name` 和 `user_id`，返回 `items`、`total`、`page`、`page_size`、`page_count` 和 `department_options`。

人员成本读取和修改继续受系统管理员权限保护，普通用户不能访问。
