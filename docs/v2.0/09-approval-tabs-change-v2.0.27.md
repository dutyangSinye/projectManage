# 芯烨工时管理系统工时审批 TAB 修改说明

> 版本：v2.0.27 ｜ 日期：2026-08-26 ｜ 状态：已完成，待业务 UAT

## 1. 修改目标

将主导航“待我审批”改名为“工时审批”，在审批页面内提供“待我审批”和“已审批”两个 TAB。待处理工时继续支持详情、通过、驳回和重新发送通知；已处理工时用于查看历史审批结果。

## 2. 行为与接口

- 新增 `GET /api/v1/approvals/processed`，返回当前用户已处理的审批任务，按处理时间倒序。
- “待我审批”使用现有 `GET /api/v1/approvals/pending`，只显示 `PENDING` 任务。
- “已审批”显示当前审批人处理过的 `APPROVED`、`REJECTED` 任务，不显示其他人的审批记录。
- 两个 TAB 均可打开同一审批详情；已处理详情只读，待审批详情继续显示操作按钮。
- 主导航、工作台入口和移动端底部导航统一使用“工时审批”文案；待处理数量仍显示在导航和待处理 TAB。

## 3. 验收标准

1. 导航和页面标题均显示“工时审批”。
2. 待我审批 TAB 只显示当前用户待处理任务，并可正常打开详情和审批。
3. 已审批 TAB 显示当前用户已通过或已驳回的历史任务，数量和排序正确。
4. 普通员工只能看到自己的审批页面数据，不能读取其他审批人的已审批记录。
5. 桌面和 390×844 移动端 TAB、列表、空态和详情无横向溢出。
