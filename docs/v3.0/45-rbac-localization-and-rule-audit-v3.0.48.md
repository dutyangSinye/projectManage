# v3.0.48 角色权限中文化与业务口径核查

- 日期：2026-09-07
- 版本：v3.0.48
- 模式：快速迭代

## 1. 修改目标

1. 管理员管理的角色权限、人员授权和生效权限界面不再展示英文技术编码。
2. 新建角色时由系统生成内部唯一编码，用户只维护中文角色名称、说明和启停状态。
3. 补齐发布、停用、冲销等操作权限的中文名称，未知权限不直接回显英文编码。
4. 核查生产环境系统管理员来源、审批流程可编辑能力和项目详情成本计算口径。

## 2. 核查结论

- 李晓天的数据库角色为“普通员工”，但生产容器通过 `SYSTEM_ADMIN_USER_IDS` 将用户 ID `24` 指定为系统管理员。
- 首次飞书管理员标记指向用户 ID `4`，与环境变量管理员是两套可同时生效的来源。
- 当前审批流程仅支持查看已发布版本；审批岗位成员可配置，但流程节点、顺序和版本尚无修改/发布接口。
- 项目详情“总成本”和“实际总成本”当前为同一指标：人员成本 + 已审批合同付款 + 已审批项目费用（扣除费用冲销）。

## 3. 验收标准

1. 管理员管理主页面、角色弹窗、人员授权弹窗和生效权限弹窗不出现英文眉题或内部编码。
2. 角色权限的全部操作名称均显示中文。
3. 新建角色无需填写角色编码且能够正常保存。
4. 前端构建、后端测试和 NAS MCP 测试通过。
