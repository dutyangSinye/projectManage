# v3.0.44 可点击高保真原型

本目录为“综合项目管理系统”v3.0.44 项目费用与动态审批工作流高保真原型，不连接生产 API，也不修改服务器数据。原型在原有 v3.0.10 完整页面基础上扩展；当前生产功能范围仍以 `../27-current-baseline-v3.0.27.md`、`frontend/` 和 `backend/` 为准。

## 页面入口

打开 `index.html` 后可通过左侧导航查看：

- 工作台：项目负责人经营区和员工工时区。
- 工时管理：我的工时、工时审批、工时看板、工时台账。
- 项目管理：项目列表、部门树筛选和项目详情。
- 项目合同：收入/支出合同、结算阶段及合同详情。
- 合同收款/付款：单据列表、新增表单和出纳审批详情。
- 项目费用：费用台账、筛选、新增费用、创建前附件、费用详情和审批确认。
- 项目看板：经营指标、收支趋势、毛利和账龄分析。
- 供应商/客户：往来单位核心信息和银行账户。
- 系统管理：人员成本、集成与通知、管理员管理、审批岗位、审批流程、基础配置。

## v3.0.44 推荐验收路径

1. 左侧进入“项目费用”，检查费用类型、审批状态和支付状态是否容易区分。
2. 点击费用单号进入详情，检查审批轨道、费用信息、支付信息、附件和时间线。
3. 点击“处理当前审批”，体验审批前二次确认和驳回原因。
4. 点击“新增费用”，切换三种费用类型，检查专属字段、附件暂存和审批路径预览。
5. 进入“审批岗位”，检查多人或签岗位和飞书人员选择方式。
6. 进入“审批流程”，查看两个预置流程、版本详情和路径演练。
7. 进入任一项目详情，切换“费用明细”，检查项目费用与总成本的关联。

实施项目样例同时展示收入合同、支出合同、收款和付款；研发项目样例默认只展示成本和支付侧。

项目详情原型支持经营分析、基本信息、人员与工时、预算、合同与资金、操作记录六个 TAB。合同详情默认铺开展示合同信息和阶段详情，合同附件固定在页面最底部；合同新增流程拆分为合同主信息、阶段列表和阶段新增弹窗。

## 原型限制

- 所有数据均为界面样例，不会写入后端。
- 保存、提交、审批和导出按钮只演示交互反馈，路由、TAB、弹窗、筛选树和移动端布局可直接演示。
- 本原型确认后，才进入生产数据库和 API 开发；原型中的静态数据不代表生产数据。
