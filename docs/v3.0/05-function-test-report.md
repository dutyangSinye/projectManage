## 3. 口径修正

历史数据存在已审批收款单但经营流水尚未补齐的情况。本版本统一以收付款单 `APPROVED` 状态作为已收/已付事实来源，经营流水继续用于审计和成本趋势，保证项目详情、项目看板和阶段明细一致。

## 4. 遗留说明

生产环境未登录直接访问业务接口会返回 `AUTH_REQUIRED`，属于飞书登录保护，不是接口故障。非飞书容器本地预览会记录 SDK `cannot find pc bridge`，不影响系统页面和后端接口。Office 预览优先由 LibreOffice 转为 PDF，若转换失败仍提供原文件下载；新版 Office 在转换不可用时回退到文本/表格只读视图，不承诺完整排版还原。
