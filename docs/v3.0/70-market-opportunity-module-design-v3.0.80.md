## 1. 表格在管什么

这份表管的是**售前漏斗 + 年度经营指标**，与现有系统正好互补：

```
【Excel 管的】 线索 → 商机 → 招投标 → 合同签订（金额预测、指标达成）
                                    ↓ 转化
【系统管的】                      项目 → 合同 → 收付款 → 成本 → 工时 → 看板
```

现有系统的入口是「项目」，Excel 的入口是「还没成项目的机会」。所以这个模块的定位是：**补齐项目立项之前的那一段，并让年度指标从 Excel 搬进系统**。

## 2. 概念映射（Excel → 系统）

| Excel 概念 | 系统落点 | 说明 |
|---|---|---|
| 板块（产品销售等 6 个） | `config_options` 新增分类 `business_segment` | 6 个固定值，复用现有配置机制，自动出现在基础配置 |
| 金额口径（跟踪/预计/已完成/暂不计入） | 商机字段 `amount_type` | **决定金额计入哪个池子**，是本模块的核心字段 |
| 商机行 | 新表 `opportunities` | 一条 = 一个客户 + 一个项目机会 |
| 推进阶段（11 级） | `config_options` 新增 `opportunity_stage` + 新表 `opportunity_stages` | 每商机 11 行阶段进度，与 Excel 逐行对应 |
| 阶段状态（✓/●/○） | `opportunity_stages.status` | DONE / CURRENT / PLANNED |
| 项目预计合同金额 | `opportunities.expected_amount` | 万元，单项工序板块由工序明细汇总回填 |
| 单项工序测算行 | 新表 `opportunity_process_items` | 工程量 × 单价 ÷ 10000 = 万元 |
| 计价工序 + 三种价格 | 新表 `process_price_book` | 21 条初始数据，可维护 |
| 年度指标总览行 | 新表 `annual_targets` | 年度 + 板块 + 目标 + 已完成 + 目标金额 |
| 目标支撑校验 | 派生计算，不落库 | 三条规则，见 §4.3 |

### 3.3 不新增表的原因

- **板块**用 `config_options` 而非独立表：只有 6 个固定值，且责任/执行部门是**年度属性**（会变），放 `annual_targets` 更合理。
- **推进阶段**用 `config_options`：与现有「项目阶段」完全同构，复用后自动获得基础配置的维护、停用、排序能力。

## 4. 计算口径（严格对齐 Excel 公式）

### 4.1 板块级

设板块 S、年度 Y：

```
预计完成金额 = Σ opportunities.expected_amount
               WHERE year=Y AND segment=S AND amount_type='EXPECTED'

跟踪金额     = Σ opportunities.expected_amount
               WHERE year=Y AND segment=S AND amount_type='TRACKING'

已完成       = annual_targets.completed_amount        ← 手工维护

年度目标     = annual_targets.annual_target
剩余指标     = 年度目标 − 已完成
完成比例     = 已完成 ÷ 年度目标
预计年度完成率 = (已完成 + 预计完成金额) ÷ 年度目标
目标完成度   = (已完成 + 目标金额) ÷ 年度目标
```

**单项工序板块的自动吻合**：该板块商机的 `amount_type` 默认 `TRACKING`，`expected_amount` 由工序明细汇总回填 → 跟踪金额 = Σ(单项预估金额) = 1586.2；因为没有 `EXPECTED` 口径的商机，预计完成金额 = 0。与 Excel 现状完全一致，**不需要为单项工序写特殊逻辑**。

### 4.2 单项工序测算

```
单项预估金额(万元) = 工程量 × 单价(元) ÷ 10000      // 工程量或单价为空则为空
项目跟踪金额(万元) = Σ 该商机下所有工序行的单项预估金额
```

### 4.3 目标支撑校验（三条规则，顺序判断）

| 条件 | 结果 | 展示 |
|---|---|---|
| 目标金额为空 | 待填写 | 灰色 |
| 目标金额 < 预计完成金额 | 目标低于预计金额 | 红色 |
| 目标金额 > 预计完成金额 + 跟踪金额 | 目标超过项目储备 | 橙色 |
| 其余 | 口径可用 | 绿色 |

### 4.4 需要修正的一处 Excel 口径不一致

总览表**产品销售行**的目标完成度公式为 `=(跟踪金额 + 预计完成金额 + 已完成) ÷ 年度目标`，而其余五行均为 `=(已完成 + 目标金额) ÷ 年度目标`。两者含义不同（前者把跟踪金额也算进去了）。

**系统统一采用其余五行的口径** `（已完成 + 目标金额）÷ 年度目标`，并保留"跟踪金额""预计完成金额"作为独立列展示。请确认这个修正是否符合预期。

## 5. 业务流程

### 5.1 商机推进

```
创建商机（选板块、客户、金额、口径）
   ↓ 自动生成 11 行阶段，第 1 阶段为 CURRENT
推进阶段 → 上一阶段置 DONE、目标阶段置 CURRENT + 填推进日期
   ↓
维护当前动作、预计签订时间、待解决问题 + 解决时间节点、协同部门
   ↓
【合同签订】阶段完成 → 可「转为项目」
```

### 5.2 商机转项目/合同（与现有系统的接缝）

点击「转为项目」时：

1. 校验：当前阶段为「合同签订」且 `status` 不是 `CONVERTED`。
2. 按**板块 → 项目大类/小类映射**生成 `projects`（建议映射见 §7 待决策）。
3. 生成**收入合同** `contracts`，金额 = `expected_amount`，往来单位 = 商机客户（客户不存在时提示先建客户）。
4. 商机置 `CONVERTED`，`amount_type` 自动改为 `COMPLETED`，回写 `converted_project_id` / `converted_contract_id`。
5. 年度指标的「已完成」按下面 §5.3 的开关决定是否自动累加。

### 5.3 「已完成」的取数开关（待决策）

Excel 里「8月已完成」是外部给定的（可能口径与合同金额不同）。建议 `annual_targets` 增加取数方式：

- `MANUAL`（默认，与现状一致）：手工填写，商机转化不影响。
- `AUTO_CONTRACT`：自动 = 该板块当年已签订收入合同金额合计（含税）。

默认先做 `MANUAL`，`AUTO_CONTRACT` 作为二期，两者可在界面上对照显示。

## 6. 权限与界面

### 6.1 菜单

新增一级菜单**「市场商机」**（code `market`，排序建议 29，放在「项目管理」之前）：

| 菜单 | code | page | 权限 |
|---|---|---|---|
| 商机管理 | `opportunities` | `opportunities` | VIEW/CREATE/EDIT/DELETE/EXPORT/IMPORT |
| 年度指标 | `annual_targets` | `annualTargets` | VIEW/CREATE/EDIT/EXPORT |
| 工序报价库 | `process_price_book` | `processPriceBook` | VIEW/CREATE/EDIT/DELETE/IMPORT |

角色建议：
- **市场营销部**：三张表全部权限（数据范围：本部门及下级）
- **管理层 / 总经理**：全部查看（数据范围：全部）
- **技术服务部 / 产品研发部**：商机 VIEW + EDIT（可推进自己协同的商机）、报价库 VIEW
- 其余角色默认无权限

数据范围复用现有四种（仅本人 / 负责项目 / 本部门及下级 / 全部数据），其中「负责项目」在商机上映射为「我负责的商机」（`owner_id`）。

### 6.2 页面设计

**① 商机管理列表**
- 筛选：年度、板块、金额口径、当前阶段、阶段状态、负责人、客户、关键词（项目信息）
- 表格列：商机编号 / 板块 / 客户（签约主体） / 项目信息 / 预计合同金额 / 金额口径 / 当前阶段 / 阶段状态 / 预计签订时间 / 负责人 / 操作
- 顶部指标条：选中年度下——跟踪金额合计、预计金额合计、商机数、平均推进阶段
- 操作：新增、编辑、删除、查看（详情）、导出 CSV、**导入 Excel**

**② 商机详情**（分区，与 Excel 逐格对应）
- 基本信息：板块、客户、项目信息、金额、口径、预计签订时间
- **阶段推进条**：11 个阶段横排/纵列，✓ ● ○ 三态，CURRENT 阶段可填推进日期并「推进到下一阶段」
- 跟进信息：当前具体动作、需要解决的问题 + 解决时间节点、协同部门
- 工序测算（仅单项工序板块）：工序行表格，可选工序→自动带单位/单价→填工程量→自动算金额；底部显示项目跟踪金额合计
- 转化区：显示已关联的项目/合同，或「转为项目」按钮

**③ 年度指标**
- 筛选年度；表格行 = 板块，列与 Excel 总览一致：年度目标 / 已完成 / 完成比例 / 剩余指标 / 预计完成金额 / 预计年度完成率 / 跟踪金额 / 目标金额(可编辑) / 目标完成度 / 支撑校验（彩色标签）
- 合计行；点板块可下钻到该板块商机列表
- 目标金额支持**行内编辑直接保存**（与填报提醒开关一致的做法）

**④ 工序报价库**
- 列表 + 新增/编辑/停用 + 导入 Excel
- 字段：工序名称、单位、三种价格、备注、来源口径

### 6.3 提醒（二期）

可复用现有 `notification_policies` 机制新增两类：
- **商机阶段超期**：CURRENT 阶段停留超过 N 天未推进 → 提醒负责人
- **问题解决到期**：`blocker_due_date` 临近/逾期 → 提醒负责人

| **三期（分析增强）** | 漏斗分析、阶段停留时长、超期提醒、目标达成预测、看板图表 | 管理层视角 |

**迁移**：Excel 现有数据量很小（15 条商机、20+ 工序行、21 条报价、6 行指标），一期可直接用导入脚本一次性灌入，无需复杂映射。导入前需先在系统里建好 6 个板块配置。

## 9. 与现有系统的边界（明确不做的事）

- 不做 CRM 全套（不做联系人、拜访记录、营销活动）
- 不改造现有项目/合同模型，转化时只做**新增**不回改
- 不改变现有成本、预算、工时口径
- 年度指标只做订单口径（与 Excel 一致），不与财务收入口径混算
