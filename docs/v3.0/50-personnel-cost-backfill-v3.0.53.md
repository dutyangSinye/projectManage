# v3.0.53 人员成本后补时回算历史审批工时

- 日期：2026-09-07
- 版本：v3.0.53
- 模式：快速迭代

## 1. 问题

工时在人员单天成本尚未配置时审批通过，系统会把单天成本快照和金额快照写为 0。之后管理人员补填人员成本，历史已审批工时不自动回算，导致项目人员成本缺失。

## 2. 修改

1. 管理员保存或更新人员单天成本后，自动回算该人员已审批/锁定、且成本快照仍为 0 的工时。
2. 回算后同步更新该工时的成本流水；已有 0 元流水直接更新，缺少流水时补记。
3. 服务启动迁移同时执行一次全量回算，已部署生产数据随本次发布自动修复。

## 3. 验收

1. 生产库中杨阳 5 天已审批工时按当前 1000 元/天回算为 5000 元成本。
2. 人员成本保存接口提交后返回前已同步成本流水。
3. 前端构建、后端回归通过。
