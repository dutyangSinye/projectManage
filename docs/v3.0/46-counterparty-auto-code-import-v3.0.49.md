# v3.0.49 客户供应商自动编码与导入简化

- 日期：2026-09-07
- 版本：v3.0.49
- 模式：快速迭代

## 1. 修改目标

1. 客户和供应商编码由系统自动生成，用户新增时不再手工填写编码。
2. 客户、供应商导入模板只保留必要业务字段，不再要求填写客户编码或供应商编码。
3. 导入校验改为按名称去重；正式导入时系统为每条客户或供应商生成唯一编码。
4. 合同导入继续按客户名称或供应商名称匹配往来单位，不受编码生成方式影响。

## 2. 编码规则

| 对象 | 自动编码格式 | 示例 |
|---|---|---|
| 客户 | `CUS-YYYYMMDD-0001` | `CUS-20260907-0001` |
| 供应商 | `SUP-YYYYMMDD-0001` | `SUP-20260907-0001` |

同一天内按已有最大流水号递增；如果历史数据中没有当日编码，则从 `0001` 开始。

## 3. 验收标准

1. 新增客户或供应商时，只填写名称等业务信息即可保存。
2. 编辑客户或供应商时编码保留为系统字段，不要求用户维护。
3. 客户导入模板列为：客户名称、付款银行、付款账号。
4. 供应商导入模板列为：供应商名称、收款银行、收款账号。
5. 重复客户名称或供应商名称能在导入预览中定位错误行。
6. 导入成功后列表中能看到系统自动生成的编码。
7. 合同导入仍能通过中文项目名称、合同类型、往来单位名称完成匹配。
