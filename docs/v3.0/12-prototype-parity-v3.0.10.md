# 综合项目管理系统原型差异补齐说明

> 版本：v3.0.10  
> 日期：2026-09-01  
> 状态：已完成
> 基线：v3.0.9 需求与系统设计

## 1. 变更目的

补齐 V3.0 原型相较当前生产系统在通知中心、业务详情、项目经营分析和系统管理页面上的真实差距。已有后端能力优先复用，金额、审批状态、权限和飞书通知仍以现有后端为唯一来源，避免改动现有业务口径。

## 2. 本版本范围

### P0

- 集成与通知增加连接概况、组织同步记录、通知策略和通知日志。
- 通知日志支持按类型、状态、时间筛选，失败记录可重试。
- 工时、收款、付款详情统一展示关联项目、合同/阶段、申请人和审批时间线。
- 合同详情统一展示合同主信息、阶段、结算率、关联单据数和底部附件区。

### P1

- 项目详情强化经营分析、成本组成、预算剩余、收付款和预警下钻入口。
- 项目看板补齐经营指标分组、应收应付账龄、趋势和风险提示。
- 客户、供应商增加筛选、摘要、详情分组和清晰操作入口；不改变现有字段。
- 人员成本、管理员管理、基础配置统一为紧凑筛选列表和弹窗维护模式。

### P2

- 工作台负责人区与员工区的视觉层级和提醒入口与原型对齐。
- 统一空状态、错误提示、加载状态、弹窗关闭防误触和移动端布局。

## 3. 不改变的内容

- 不修改工时日期校验、同人同日唯一、审批通过计入成本等既有规则。
- 不修改应收/应付只统计已到期阶段剩余金额的口径。
- 不修改客户、供应商、合同附件和收付款数据结构的兼容性。
- 不引入飞书回调依赖，继续使用主动查询和应用消息通知。

## 4. 验收标准

1. 集成页面能看到连接状态、同步结果和通知发送记录；失败通知显示原因并能重试。
2. 合同、收款、付款、工时和项目详情均能从列表进入完整详情，不出现空白或错误对象提示。
3. 项目经营指标与后端接口返回一致，预算、成本、收入、收付款和预警不重复计算。
4. 客户、供应商、人员成本和管理员页面的筛选、分页、编辑入口可用，未授权模块继续隐藏。
5. 前端构建、后端编译和既有测试全部通过，桌面端不出现无意义横向滚动。

## 5. 实现与验证记录

- 集成与通知中心已接入概况、组织同步历史、通知策略、通知日志和失败重试。
- 合同、收款、付款、工时和项目详情已补齐关联信息、审批时间线、阶段和附件入口。
- 项目经营分析、项目看板、客户/供应商筛选、人员成本和管理员管理已与现有接口联动。
- 前端生产构建、Python 编译和 17 条后端回归测试通过。
- 使用最新后端隔离端口完成桌面端页面回归；`390×844` 移动端核心页面无横向溢出。
- 修复工作台项目表在窄屏下固定宽度撑大页面的问题，横向滚动限制在表格容器内部。
