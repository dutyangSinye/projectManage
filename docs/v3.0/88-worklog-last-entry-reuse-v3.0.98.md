# v3.0.98 工时快捷填报说明

日期：2026-10-19
状态：已确认执行
类型：快速通道（工时填报交互优化）

## 1. 需求

新增工时时支持快速带入上一次填写的工时内容，减少重复选择项目和重复输入工作描述的操作。

## 2. 交互方案

- 仅在“新增工时”页面显示“带入上次工时”按钮；编辑现有草稿或驳回记录时不显示。
- “上次工时”按当前用户最近创建的工时记录确定。
- 点击后带入：工时类型、项目、项目阶段、工作状态和工作描述。
- 不带入：填报日期、开始日期、结束日期和工时天数；这些字段继续使用本次新建时的日期，并按工作日历自动计算。
- 当前用户没有历史工时时按钮禁用。
- 上次记录关联的项目已不可填报时，带入其余内容、清空项目，并提示用户重新选择项目。
- 历史类型编码自动映射到当前类型：历史项目工时按项目分类映射为研发项目工时或技术服务工时，历史管理/其他/观摩推广类型映射为当前同类编码。

## 3. 影响范围

- 仅调整前端新增工时表单，不新增接口，不修改工时表结构和审批规则。
- 现有新增、编辑、保存草稿、保存并提交、日期校验、项目选择器和移动端吸底操作条保持原逻辑。

## 4. 验收标准

1. 有历史工时时，点击按钮可一次带入工时类型、可用项目、阶段、工作状态和描述。
2. 带入后，本次填报日期、开始日期、结束日期和工时天数不变。
3. 无历史工时时按钮不可点击。
4. 上次项目不可用时不能保留无效项目，并显示重新选择项目的提示。
5. 编辑草稿或驳回工时时不显示快捷带入按钮。
6. 最近记录使用历史工时类型编码时仍可正常带入，不出现“类型不可用”。
