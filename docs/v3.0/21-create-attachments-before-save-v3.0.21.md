# 新建合同与收付款单预选附件说明

- 版本：v3.0.21
- 日期：2026-09-01
- 状态：已实现并完成回归
- 适用系统：综合项目管理系统

## 需求

合同、收款单和付款单在新建时即可选择附件，不要求用户先保存单据再重新打开上传。由于后端附件必须绑定已存在的实体 ID，本版本采用前端暂存、保存后自动关联上传的方式。

## 交互规则

1. 新建合同、收款单或付款单时，附件区域允许一次选择多个文件，并在弹窗内显示待上传文件名和大小。
2. 点击保存、保存草稿或提交后，先创建/更新业务实体；实体保存成功后，按选择顺序自动上传暂存附件。
3. 编辑已有实体时，附件继续沿用即时上传方式；已保存附件支持预览、下载和删除。
4. 自动上传期间显示上传状态；业务实体保存成功但部分附件失败时，保留单据并明确提示失败文件，不回滚已保存的单据。
5. 预览、下载和删除仍只对已成功关联的附件开放；新建表单关闭或取消时清除未上传的本地文件队列。
6. 附件类型和单文件 50MB 限制沿用现有合同及收付款附件接口。

## 技术影响

- 前端新增合同、收款单、付款单各自的 `File[]` 暂存队列。
- 复用现有合同附件和收付款附件上传接口，不修改后端数据表和接口契约。
- 保存函数在取得实体 ID 后调用批量上传辅助逻辑，再刷新附件列表。

## 验收标准

- 三类新建弹窗均可选择多个附件，且未保存时不会调用附件接口。
- 保存成功后附件自动出现在当前弹窗的附件列表中。
- 编辑已有合同、收款单、付款单的即时上传、预览、下载、删除不受影响。
- 保存失败时不上传暂存附件；实体保存成功但附件上传失败时，错误信息包含失败文件名。
- 前端生产构建、后端编译和既有回归测试通过。
