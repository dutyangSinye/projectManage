# v3.0.85 费用复核重复审批防抖与幂等修复

版本：v3.0.85  
日期：2026-09-22  
状态：已实现

## 1. 问题

审批人工成本结转时，页面先提示“复核已通过”，随后又出现 `PROJECT_COST_ENTRY_NOT_PENDING_REVIEW`。从现象看，第一次请求已经成功把单据从“待复核”改为“已通过”，第二次重复请求再次进入后端时，由于单据不再是“待复核”，触发 409 状态校验。

## 2. 修复方案

### 2.1 前端防重复

- 费用复核列表为每条单据维护处理中标记。
- 点击“通过”后立即禁用该单据按钮，并显示“处理中…”。
- 列表刷新后自动清理已离开“待复核”的处理中标记。
- 成本单详情页“复核通过”按钮增加全局处理中状态，防止连点。

### 2.2 后端幂等

`POST /api/v1/project-cost-entries/{entry_id}/approve` 调整为：

- `PENDING_REVIEW`：正常复核通过，写项目成本流水；
- `APPROVED`：视为重复请求，直接返回当前单据详情，不再报错、不再写流水；
- 其他状态：继续返回 `PROJECT_COST_ENTRY_NOT_PENDING_REVIEW`。

## 3. 验证要点

- 人工成本结转/项目费用首次复核通过正常计入成本。
- 重复点击“通过”不会弹出错误。
- 重复请求不会重复生成 `PROJECT_COST_ENTRY` 项目流水，成本只计入一次。
