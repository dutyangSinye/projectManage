# 客户、供应商与合同导入设计

> 文档版本：v3.0.49 ｜ 日期：2026-09-07 ｜ 状态：已实现并验证

## 1. 目标

在客户、供应商、项目合同管理页面增加批量导入能力。用户可以下载只包含必要字段的 Excel 模板，上传 Excel 或 CSV，先预览并校验，校验全部通过后一次性写入数据库。

## 2. 模板字段

| 导入类型 | 必要字段 | 可选字段 |
|---|---|---|
| 客户 | 客户名称 | 付款银行、付款账号 |
| 供应商 | 供应商名称 | 收款银行、收款账号 |
| 合同 | 合同编号、合同名称、项目名称、合同类型、往来单位名称、合同金额 | 合同类型使用下拉框 |

客户和供应商编码由系统自动生成，导入文件不再填写编码。合同类型填写中文“收入合同”或“支出合同”，模板提供下拉框。收入合同填写客户名称，支出合同填写供应商名称，系统按名称自动匹配并保存对应的往来单位编码；系统内部仍使用 `INCOME`/`EXPENSE`。项目填写项目名称，系统按名称匹配项目并保存项目编码。合同导入后状态固定为草稿，合同阶段在合同详情中单独维护。

## 3. 交互流程

1. 在客户、供应商或项目合同页面点击“导入”。
2. 在导入弹窗下载对应模板并选择 `.xlsx` 或 `.csv` 文件。
3. 点击“开始校验”，页面展示前几行数据和全部错误行、字段、原因。
4. 有错误时禁止导入，用户修改文件后重新上传；无错误时才显示“确认导入”。
5. 导入成功后关闭弹窗并刷新当前列表；遮罩点击不关闭弹窗，避免误操作。

## 4. 接口与权限

| 接口 | 用途 | 权限 |
|---|---|---|
| `POST /api/v1/imports/customers/preview` | 客户文件校验和预览 | 客户与供应商 VIEW |
| `POST /api/v1/imports/customers` | 批量导入客户 | 客户与供应商 CREATE |
| `POST /api/v1/imports/suppliers/preview` | 供应商文件校验和预览 | 客户与供应商 VIEW |
| `POST /api/v1/imports/suppliers` | 批量导入供应商 | 客户与供应商 CREATE |
| `POST /api/v1/imports/contracts/preview` | 合同文件校验和预览 | 项目合同 VIEW |
| `POST /api/v1/imports/contracts` | 批量导入合同 | 项目合同 CREATE |

导入接口接收 `multipart/form-data`，单文件最大 5MB。返回中文可读错误，禁止把对象直接拼接为 `[object Object]`。

## 5. 校验与一致性

- 必填字段不得为空；文件内部名称或合同编号不得重复。
- 客户、供应商名称不得与数据库现有记录重复；编码由系统按日期流水自动生成。
- 合同项目名称必须匹配当前数据范围内的唯一项目；匹配不到或同名项目超过一个时，预览报错并禁止导入，修正文件后重新导入。
- 合同往来单位名称必须与合同类型匹配且存在，系统自动转换为对应的往来单位编码。
- 合同金额必须为大于等于 0 的数字。
- 预览校验不写数据库；正式导入先完成全部校验，再在同一事务中批量写入，任一异常则整体回滚。
- 每条新增合同写入操作审计日志；客户和供应商沿用现有审计规则。

## 6. 交付验收

- 三种模板可下载，表头和填写说明清晰，合同类型有中文下拉约束。
- Excel、UTF-8 CSV、GB18030 CSV 均可读取。
- 正确数据可导入；重复名称或合同编号、项目名称不存在、合同类型非法、合同类型与往来单位不匹配、金额非法均能定位到行和字段。
- 校验失败时数据库无新增记录；导入成功后列表可见且合同为草稿。
- 无导入权限的用户不显示入口，直接调用接口也会被后端拒绝。
