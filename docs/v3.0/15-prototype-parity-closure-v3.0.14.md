# 原型差异闭环修订说明

- 版本：v3.0.14
- 日期：2026-09-01
- 状态：编码前修改说明
- 适用系统：综合项目管理系统

## 本轮目标

将上一轮“接口和入口已存在”的实现补齐到“页面可见、可操作、可下钻、数据上下文完整”。本轮不改变既有业务口径，不替换 Docker 数据卷，不改变飞书回调方案。

## 闭环范围

| 模块 | 本轮闭环 | 验收口径 |
| --- | --- | --- |
| 集成与通知 | 将通知记录从集成概况中提升为独立通知中心视图；保留类型/状态筛选、详情、失败原因和重试 | 管理员进入“通知中心”即可分页查看全部工时、合同阶段、预算和收付款通知 |
| 集成与通知 | 同步时间线、策略管理与概况分区明确 | 可看到连接状态、组织人数、今日发送、待重试、新增/更新统计、策略保存结果 |
| 项目详情 | 合同与资金页签增加收入/支出合同、收款单、付款单的关联子视图 | 可从项目详情直接查看合同阶段、单据状态和余额，并下钻合同/单据详情 |
| 项目详情 | 人员与工时页签增加审批摘要与规则信息 | 已审批、待审批、审批链和工时规则在同一页可核对 |
| 合同管理 | 合同主信息、结算概况、阶段明细和附件保持分层展示 | 点击合同名称进入详情后，结算率、单据数和阶段列表无需额外点击即可看到 |
| 收付款管理 | 列表和详情入口统一，详情展示项目、合同、阶段、往来单位、账户、阶段余额及审批时间线 | 收款、付款均可从编号/查看进入详情；审批动作保留二次确认 |
| 项目看板 | 图表、经营汇总、预警和项目明细建立统一下钻提示；补齐无数据状态 | 图表随筛选刷新，项目名称/图表项目/预警均可进入项目详情或单据详情 |

## 不变约束

- 已审批收付款才计入已收/已付，已审批工时才计入人天和人员成本。
- 应收只统计已到期收入阶段未收金额；应付只统计已到期支出阶段未付金额。
- 飞书只负责组织同步和应用消息通知，本地系统保存业务审批状态。
- 维持现有浅色业务系统风格，不引入 Element Plus。

## 关联回归

本轮修改后必须回归：登录与管理员菜单权限、集成概况与组织同步、通知策略保存/重试、项目详情六页签、合同详情和阶段维护、客户/供应商实时名称、合同收付款审批与通知、项目看板筛选/图表/导出，以及桌面端和 390×844 移动端布局。
