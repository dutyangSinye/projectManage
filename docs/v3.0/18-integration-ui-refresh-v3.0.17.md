# 集成与通知界面优化

## 版本信息

- 版本：v3.0.17
- 日期：2026-09-01
- 状态：已实现

## 调整说明

本次为集成与通知页面的界面迭代，不改变现有接口、通知策略存储和发送逻辑。页面改为“状态概览 → 集成概况/通知中心 → 业务内容”的信息层级，提升管理员对连接状态、组织同步和通知发送情况的判断效率。

### 集成概况

- 顶部展示飞书连接、组织成员、今日发送、待重试、部门数量和累计成功数等关键指标。
- 组织架构同步卡片突出当前连接状态、最近同步摘要、同步操作和同步记录时间线。
- 通知策略按审批提醒、合同阶段、经营预警分组，策略行采用紧凑控件布局，保留启用、通道、提前天数和保存能力。

### 通知中心

- 保留类型/状态筛选、查询、重置、详情、失败重试和分页能力。
- 优化筛选工具栏、列表表头和状态信息布局，避免操作区错位。

### 响应式要求

- 桌面端采用概览指标 + 双栏业务区布局。
- 移动端自动切换为单列，策略控制区可换行，页面不得产生横向滚动。

## 验证

- 前端 TypeScript/Vite 生产构建通过。
- 回归集成概况、通知中心的现有查询、同步、保存策略、详情和失败重试入口。
