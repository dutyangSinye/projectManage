# 综合项目管理系统 v3.0.37：飞书授权调用修正

- 版本：v3.0.37
- 日期：2026-09-05
- 状态：已确认，进入实现

## 1. 问题

生产页面点击“使用飞书登录”后停留在“正在打开飞书授权…”。现有逻辑优先调用 `tt.requestAccess`，部分飞书客户端或版本虽然暴露该方法，但调用后不返回回调，导致标准登录调用没有机会执行。

## 2. 方案

- 以飞书 H5 登录的标准 `tt.requestAuthCode` 作为首选授权接口。
- 仅在标准接口不可用时使用 `tt.requestAccess` 兼容路径。
- 保持 `h5sdk.ready` 初始化、成功/失败回调、8 秒统一超时和错误信息清理逻辑。
- 不修改后端 OAuth 换码、用户同步、权限和业务数据。

## 3. 验收标准

1. 在飞书客户端内点击登录后，直接进入 `requestAuthCode` 授权流程。
2. 标准接口返回授权码后可以正常换取登录会话。
3. 标准接口不可用时仍可使用兼容授权路径。
4. 任一 SDK 无回调时 8 秒内结束加载并显示明确提示。
5. 普通浏览器仍提示必须使用飞书账号登录，不伪造授权成功。
