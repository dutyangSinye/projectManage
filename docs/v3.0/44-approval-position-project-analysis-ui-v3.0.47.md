# 审批岗位与项目经营概况界面优化说明

- 版本：v3.0.47
- 日期：2026-09-07
- 状态：已发布
- 影响范围：审批岗位、项目详情概况、费用审批通知回归

## 1. 修改目标

1. 审批岗位从重复卡片改为紧凑岗位名册，固定展示岗位职责、已配置成员、启停状态和配置入口。
2. 岗位配置弹窗强化人员检索、已选人数和成员状态，降低组织人员较多时的查找成本。
3. 项目详情顶部经营指标增加独立“项目费用”，明确费用预算、已用金额和使用率。
4. “成本组成与预算执行”按总预算、成本组成和专项预算三层呈现，避免总成本预算与费用子预算混在同一组数字中。
5. 回归费用审批飞书通知：提交通知当前节点、流转通知下一节点、终态通知申请人，保留详情直达链接和幂等记录。

## 2. 页面结构

### 2.1 审批岗位

- 顶部摘要：岗位总数、启用岗位数、已配置岗位数、岗位成员人次。
- 主体列表：状态标识、岗位名称/编码、岗位职责、成员名单、人数、配置按钮。
- 无成员岗位使用明确的“待配置”状态，不用大块空白占位。
- 配置弹窗：岗位基本信息与成员选择分区；支持按姓名、部门检索；显示已选择人数；保存按钮保持唯一主操作。

### 2.2 项目经营概况

- 顶部六项：收入合同、支出合同、总成本、项目费用、毛利/毛利率、未完成预警。
- 总成本预算区：成本预算、实际总成本、预算剩余/超支、总成本使用率及主进度条。
- 成本组成区：人员成本、合同成本、项目费用逐行展示金额、占比和横向构成条。
- 专项预算区：人天预算执行、人员成本基线、费用预算执行，分别展示口径说明。
- 近六个月趋势保留，但与预算和成本组成分区，不再挤在同一数字矩阵内。

## 3. 业务口径

- 总成本 = 已审批工时对应人员成本 + 已确认合同成本 + 已审批项目费用。
- 成本预算剩余 = 成本预算 - 总成本。
- 费用预算为项目费用专项额度，不与总成本预算相加形成新的总预算。
- 费用预算使用率 = 已审批项目费用 / 费用预算。
- 本次不修改后端金额算法，只优化既有字段的展示关系。

## 4. 验收标准

1. 1440px 桌面端审批岗位无需卡片式跳读，成员、职责和操作按列对齐。
2. 岗位成员可按姓名或部门即时筛选，已选成员在筛选后仍保持选择状态。
3. 项目详情顶部明确显示项目费用及费用预算使用情况。
4. 成本预算、实际总成本、三类成本组成、费用预算的父子关系清晰，金额和比例不重叠。
5. 390x844 移动端项目详情无横向溢出；审批岗位列表可自然折行。
6. 前端构建、后端回归测试通过。
7. 生产环境费用通知策略为飞书应用通道，现有费用审批通知记录为成功；自动化测试覆盖节点通知和结果通知。

## 5. 关联回归

- 费用提交、节点通过、驳回、最终审批和出纳支付通知。
