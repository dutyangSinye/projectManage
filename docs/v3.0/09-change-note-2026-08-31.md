# 综合项目管理系统变更说明

## 1. 变更范围

- 对比日期：2026-08-30（前天）至 2026-08-31（昨天）。
- 对比依据：当前工作区文件修改记录、v3.0 变更日志、设计文档和测试报告。
- 结论：未发现 2026-08-30 当日新增的业务源代码或设计文档修改；2026-08-31 主要完成 v3.0 合同管理与合同附件能力的集中落地和发布修复。

## 2. 功能新增与调整

### 2.1 合同详情页

- 合同管理中点击合同名称进入独立合同详情页。
- 合同详情页直接平铺展示合同摘要、合同基本信息和全部合同阶段。
- 阶段列表、阶段新增、阶段编辑职责分离，避免把新增表单和阶段查看混在一起。
- 项目详情页“合同与资金”中的收入合同、支出合同名称均可进入合同详情。
- 阶段详情直接展示计划金额、已收/已付、未收/未付、结算率、关联单据数和阶段状态。
- 合同详情页内容顺序调整为：合同信息、阶段详情、合同说明、合同附件；附件固定放在页面最下方。

### 2.2 合同附件

- 新增合同附件的持久化、上传、列表、预览、下载和删除功能。
- 合同新增或编辑时，先保存合同主数据，再在同一弹窗继续上传附件。
- 合同详情页提供附件列表和操作入口，沿用合同管理权限及项目数据范围。
- 支持 `.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt`、`.pptx`、PDF 和常见图片格式。
- 附件记录保存原始文件名、类型、大小、上传人和上传时间；服务器使用随机存储名，避免同名覆盖和路径注入。

### 2.3 Office 预览

- DOCX、XLSX、PPTX 使用只读 HTML 预览。
- DOC、XLS、PPT 使用 LibreOffice 转 PDF 后进行预览。
- PDF 和图片支持系统内预览。
- 预览改为系统内弹窗，减少新标签页被浏览器或飞书内置浏览器拦截的问题。
- 预览失败时仍保留原文件下载能力，不影响附件使用。
- 后端补充中文 CJK 字体，改善中文 Word/PPT 转换后的字体、换行和版式稳定性。

## 3. 问题修复

- 修复 NAS Nginx 默认 1MB 请求体限制导致合同附件上传失败的问题。
- 网关上传上限调整为 64MB，后端继续执行单文件 50MB 业务校验。
- 前端对 HTTP 413 返回明确的文件大小提示。
- 修复 LibreOffice 未安装或预览转换失败时的错误兜底，避免附件预览接口返回 500。
- 修复 NAS 发布包遗漏后端 Dockerfile 的问题，确保实际构建镜像包含 LibreOffice 和中文字体依赖。
- 修复合同详情页附件位置不符合信息阅读顺序的问题，将附件调整到页面最底部。

## 4. 部署与运行环境

- Compose 后端构建改为使用随发布包同步的 `deploy/Dockerfile.backend`。
- 发布时同步前端构建产物、后端应用代码、后端依赖、Dockerfile、Compose 和 Nginx 配置。
- NAS 发布过程保留部署文件备份，不删除或替换 Docker 数据卷。
- NAS 前后端容器重建完成，首页和 `/health` 接口均返回 HTTP 200。
