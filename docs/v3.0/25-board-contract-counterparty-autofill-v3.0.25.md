# 项目看板与合同往来账户自动带出

- 版本：v3.0.25
- 日期：2026-09-01
- 状态：已实现并部署验证

## 修改说明

1. 项目看板筛选选择“全部项目”时，项目选择器使用当前用户可访问的完整项目列表动态加载，不因“全部项目”而只显示当前已汇总结果或项目负责人范围。
2. 新建或编辑收款单选择收入合同后，根据合同客户实时带出付款方名称、付款银行和付款账号；字段仍可人工修改。
3. 新建或编辑付款单选择支出合同后，根据合同供应商实时带出收款方名称、收款银行和收款账号；字段仍可人工修改。
4. 每次切换合同时按新合同重新回填；回填完成后字段仍可人工修改，保存时以表单当前值为准。

## 影响范围

- 前端：项目看板筛选、收款单表单、付款单表单。
- 后端：复用现有项目、合同、客户、供应商接口和账户字段，不改变数据库结构与审批接口契约。

## 接口契约

- `GET /api/v1/projects/board/options?data_scope=OWNED|ALL`：返回当前用户在项目看板数据范围内可选择的未删除项目，系统管理员在 `ALL` 下可获得全部项目。
- 收付款保存接口继续接收 `payer_name/payer_bank_name/payer_bank_account` 或 `payee_name/payee_bank_name/payee_bank_account`，不改变单据快照字段和审批流程。

## 验收标准

- 看板选择“全部项目”后，项目下拉项来自完整可访问项目集；重新查询后统计范围仍为全部项目。
- 收款合同切换后正确带出客户账户三项；付款合同切换后正确带出供应商账户三项。
- 保存接口提交带出后的字段，且人工修改值可保存。
- 原有项目筛选、项目看板查询、合同收付款审批流程回归通过。
