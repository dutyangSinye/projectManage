# 通知策略统一编辑

- 版本：v3.0.26
- 日期：2026-09-01
- 状态：已实现并部署验证

## 修改说明

1. 集成与通知页面的通知策略区域改为只读状态，平时展示每条策略的启用状态、发送通道和阶段提醒天数。
2. 策略区域右上角提供“修改”入口，统一在弹窗中编辑所有通知策略。
3. 弹窗只有一个“统一保存”按钮，保存时一次提交全部策略；取消或关闭不改变已生效配置。
4. 后端增加批量保存接口，并保留原单条 PATCH 接口兼容历史调用方。

## 接口契约

- `PUT /api/v1/integrations/policies`
- 请求：`{"items":[{"notification_type":"...","enabled":true,"send_channel":"app|webhook|mock","remind_days_before":0}]}`
- 返回：`NotificationPolicyList`，包含保存后的完整策略列表。
- 权限：需要集成与通知的 `CONFIGURE` 权限；缺少策略、重复策略或未知策略类型时整体拒绝保存。

## 验收标准

- 页面默认不可编辑，没有逐条保存按钮。
- 点击右上角“修改”打开弹窗，所有策略可编辑。
- 点击“统一保存”后所有修改一次生效；任一校验错误时不更新任何策略。
- 关闭/取消弹窗后，未保存草稿不影响页面已生效值。
