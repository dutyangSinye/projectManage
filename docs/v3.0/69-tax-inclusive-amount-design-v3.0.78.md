# v3.0.78 含税/未税金额设计

日期：2026-09-15  
状态：已确认执行  

## 背景

合同、合同阶段、合同收款、合同付款、项目费用原先只有一个“金额”字段。随着项目经营分析进入财务口径，需要同时保存含税金额与未税金额，避免应收应付、银行收付金额和毛利分析混用。

## 设计原则

1. 兼容历史数据：现有 `amount` 字段不删除，统一解释为“含税金额”。
2. 新增未税字段：新增 `amount_without_tax`、`tax_rate`、`tax_amount`。
3. 历史默认口径：旧数据迁移时 `amount_without_tax = amount`，`tax_rate = 0`，`tax_amount = 0`。
4. 资金类口径：合同金额、阶段计划金额、应收未收、应付未付、已收、已付默认继续按含税金额计算。
5. 经营分析口径：项目看板和详情逐步支持未税收入、未税成本、税额展示；本版本先完成数据结构、表单录入、详情和列表展示。

## 涉及对象

| 对象 | 原字段 | 新含义 | 新增字段 |
|---|---|---|---|
| 合同 | `amount` | 合同含税金额 | `amount_without_tax`、`tax_rate`、`tax_amount` |
| 合同阶段 | `amount` | 阶段含税金额 | `amount_without_tax`、`tax_rate`、`tax_amount` |
| 合同收款单 | `amount` | 本次收款含税金额 | `amount_without_tax`、`tax_rate`、`tax_amount` |
| 合同付款单 | `amount` | 本次付款含税金额 | `amount_without_tax`、`tax_rate`、`tax_amount` |
| 项目费用/人工成本结转 | `amount` | 本次成本含税金额 | `amount_without_tax`、`tax_rate`、`tax_amount` |

## 计算规则

前端与后端均使用同一套规则：

- 输入含税金额与税率时：`未税金额 = 含税金额 / (1 + 税率)`，四舍五入到 2 位。
- 税额：`税额 = 含税金额 - 未税金额`。
- 如果用户没有传未税金额，后端自动按含税金额和税率计算。
- 如果用户传了未税金额，后端以用户传入值为准并重算税额。
- 税率保存为小数，例如 6% 保存为 `0.06`。

## 前端交互

金额录入区统一为四项：

```text
含税金额 *    税率
未税金额      税额
```

- 用户主要填写“含税金额”和“税率”。
- 未税金额自动计算，但允许手工调整。
- 税额只读展示。
- 原列表里的“金额”文案统一改为“含税金额”，并补充“未税金额”列或详情展示。

## 后端接口兼容

- 新字段为可选字段，旧请求只传 `amount` 仍可正常保存。
- 后端视图统一返回含税、未税、税率、税额四个字段。
- 导入模板和历史接口不强制立即改造，未传税率时按 0 税率兼容。

## 本版本交付范围

1. 数据库字段与自动迁移。
2. 后端入参、出参、自动税额计算。
3. 合同、阶段、收款、付款、项目成本单的创建/修改保存。
4. 前端表单和详情页展示含税/未税金额。
5. 变更记录与构建、测试、部署。

## 后续建议

项目看板下一步可以增加“含税/未税口径切换”，并在毛利分析中默认使用未税收入与未税成本。
