# v3.0.54 人员成本流水去重修复

- 日期：2026-09-07
- 版本：v3.0.54
- 模式：快速迭代

## 1. 问题

v3.0.53 启动迁移在已存在规范成本流水时，又按旧幂等键插入了一条人员成本流水，造成同一工时被计入两次，项目人员成本翻倍。

## 2. 修改

1. 启动迁移补流水时按 `entry_type + source_type + source_id` 判断是否已存在，不再只看单一幂等键。
2. `add_ledger_entry()` 同样按业务来源三元组幂等，兼容历史旧幂等键记录。
3. 启动时清理同源重复的旧格式 `personnel:*` 流水，保留规范流水。

## 3. 验收

1. 生产库“机器人集群智能调度管理系统”杨阳 5 天工时仅保留一条 5000 元人员成本流水。
2. 项目人员成本合计回到 5000 元，不再翻倍。
3. 后端全量回归通过。
