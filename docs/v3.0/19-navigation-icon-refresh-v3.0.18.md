# 导航图标优化

## 版本信息

- 版本：v3.0.18
- 日期：2026-09-01
- 状态：已实现

## 调整说明

将桌面侧栏、折叠侧栏和移动端底部导航中的文字字符图标替换为统一的 SVG 图形资源。保留原有菜单名称、权限判断、激活状态、审批数量和页面跳转逻辑，仅改善图标识别、尺寸比例和对齐效果。

### 设计规则

- 采用 20px 统一画布和 1.8px 线条，保证各业务模块图标视觉重量一致。
- 使用现有系统青绿色作为激活态颜色，默认态使用低对比灰绿色。
- 桌面侧栏图标固定在 20px 图标槽位内，移动导航使用 20px 图标和文字上下布局。
- 图标资源放在前端公共目录，通过 SVG symbol 引用，避免字体字符在不同系统中的形态差异。

## 验证

- 前端 TypeScript/Vite 生产构建通过。
- 回归桌面侧栏、窄屏侧栏、移动底部导航的菜单显示、激活态和权限隐藏逻辑。
