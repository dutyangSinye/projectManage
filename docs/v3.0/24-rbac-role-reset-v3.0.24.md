# RBAC 角色配置重置说明

- 版本：v3.0.24
- 日期：2026-09-01
- 状态：已实现，已发布
- 适用系统：综合项目管理系统

## 1. 调整内容

本次不再保留旧版权限迁移和上一版本预置的业务角色。系统启动时只保留“系统管理员”角色，其他角色配置全部清空，管理员可以按实际组织岗位重新创建角色并授权。

## 2. 清理范围

- 删除除 `system_admin` 外的全部角色，包括内置角色、自定义角色和历史迁移角色。
- 清空全部人员角色绑定和人员数据范围覆盖。
- 删除非系统管理员角色的菜单操作权限和数据访问范围。
- 清空旧版 `admin_permissions` 记录。

以下数据不清理：用户、飞书组织架构、项目、合同、合同阶段、收付款单、工时、附件、通知和审计业务数据。

## 3. 保留规则

- `system_admin` 角色继续保留全部菜单、全部操作和全部数据范围。
- `SYSTEM_ADMIN_USER_IDS` 继续作为系统管理员最高权限兜底。
- 未重新配置角色的普通用户默认不显示管理菜单，访问受保护接口返回 `403 PERMISSION_REQUIRED`。
- 清理通过一次性版本标记执行；v3.0.24 首次启动完成清理后，后续重启不会删除管理员重新创建的角色。

## 4. 重新配置路径

1. 使用系统管理员进入“系统管理 → 管理员管理”。
2. 新建自定义角色，配置菜单、操作权限和默认数据范围。
3. 在“人员授权”中为飞书组织人员绑定角色。
4. 使用“生效权限”确认菜单、操作和数据范围后，再交给用户使用。
