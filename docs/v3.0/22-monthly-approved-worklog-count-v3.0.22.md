# 本月工时审批数口径说明

- 版本：v3.0.22
- 日期：2026-09-01
- 状态：已实现并完成回归
- 适用系统：综合项目管理系统

## 需求

工作台“我的工时”区域的首个指标改为“本月总计工时审批数”，用于显示当前自然月已经审批完成的工时单据数量，不再显示工时天数合计。

## 统计口径

统计当前用户的工时记录，同时满足以下条件：

1. 工时开始日期属于当前 `Asia/Shanghai` 自然月；
2. 工时状态为 `APPROVED`（已审批）或 `LOCKED`（已锁定）。

每条工时记录计 1 笔，不使用 `quantity` 或 `unit` 累加。没有符合条件的记录时显示 `0 笔`。

## 影响范围

- 工作台“我的工时”指标文案改为“本月总计工时审批数”。
- “我的工时”列表上方的已通过摘要同步显示本月已审批工时单据笔数。
- 工时列表接口不变，前端按当前月份过滤，避免影响历史查询和审批数据。

## 验收标准

- 本月有 3 条已审批/已锁定工时时显示 `3 笔`。
- 上月或更早的已审批工时不计入本指标。
- 本月草稿、审批中、驳回工时不计入本指标。
- 指标不受每条工时 quantity 为 0.5、1 或多天的影响，每条记录只计 1 笔。
