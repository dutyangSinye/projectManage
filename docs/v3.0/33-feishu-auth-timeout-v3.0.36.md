# 综合项目管理系统 v3.0.36：飞书授权无响应兜底

- 版本：v3.0.36
- 日期：2026-09-05
- 状态：已确认，进入实现

## 1. 问题

在飞书客户端内点击“使用飞书登录”后，如果授权 SDK 已加载但既不执行成功回调也不执行失败回调，页面会一直停留在授权处理中，用户看起来像是点击没有反应。

## 2. 方案

- 授权流程一开始即启动统一超时计时器，覆盖 `h5sdk.ready`、`tt.requestAccess` 和 `tt.requestAuthCode` 全部路径。
- 授权成功、失败或超时后统一清理计时器，避免重复处理。
- 超时提示明确指导用户关闭当前页面后从飞书重新打开；既有 `requestAccess`/`requestAuthCode` 兼容回退逻辑保持不变。
- 普通浏览器仍不伪装成飞书授权环境，继续提示用户在飞书客户端内打开系统。

## 3. 验收标准

1. 点击登录后立即进入加载状态。
2. SDK 无成功或失败回调时，8 秒内显示明确的授权无响应提示，不再无限加载。
3. SDK 成功返回授权码时，正常换取登录会话。
4. SDK 失败时，仍保留现有错误码描述和兼容授权回退。
5. 未在飞书客户端打开时，显示明确的环境提示。

## 4. 影响范围

- 前端飞书登录入口和授权调用链。
- 不修改后端认证接口、用户同步逻辑、业务数据和生产数据库。
