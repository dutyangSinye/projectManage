# 工时填报日期改造说明（v3.0.72）

## 背景

原工时记录只有「开始日期 / 结束日期」和提交时间。实际业务中需要区分：

- 填报日期：员工在哪一天填写这条工时单；
- 工时日期：这条工时实际覆盖的工作日期区间。

因此本版本新增独立字段「填报日期」，用于工时填报、工时审批和后台工时台账展示。

## 实现范围

### 前端

- 工时填报新增「填报日期」输入项，默认当天。
- 编辑工时时回显原填报日期；旧数据没有填报日期时回退显示开始日期。
- 工时提交结果页、工时审批列表、工时审批详情展示填报日期。
- 后台工时台账展示「填报 / 工时日期」，编辑弹窗可维护填报日期。
- 后台工时台账筛选项改为「填报开始日期 / 填报结束日期」。

### 后端

- `worklogs` 表新增 `fill_date` 字段。
- 新建库按模型直接生成非空字段；既有库启动迁移时先补列，再用 `start_date` 回填历史记录。
- 新建工时、员工编辑工时和管理员编辑工时时均保存 `fill_date`；未传时默认使用 `start_date`。
- 后台工时台账查询、排序和导出按 `fill_date` 口径处理。
- CSV 导出新增「填报日期」列。

## 不改变的业务规则

- 工时天数仍按开始日期到结束日期之间的工作日自动计算。
- 同一人员同一天不可重复填报的校验仍按工时开始/结束日期区间判断。
- 开始日期和结束日期仍不能跨月。
- 审批流程、飞书通知和项目成本统计不因填报日期改变。

## 兼容与迁移

- 历史数据：`fill_date = start_date`。
- 旧客户端：如果没有提交 `fill_date`，后端自动使用 `start_date`。
- 新增索引：`ix_worklogs_user_fill_date`，服务启动时幂等创建。

## 验证清单

- 显式提交填报日期时，接口返回相同填报日期。
- 不提交填报日期时，接口返回填报日期等于开始日期。
- 工时审批和工时台账能展示填报日期。
- 工时台账导出包含「填报日期」列。
- 前端生产构建通过；后端测试通过。
