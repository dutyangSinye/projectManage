# 综合项目管理系统 v3.0.40：飞书授权立即启动

- 版本：v3.0.40
- 日期：2026-09-05
- 状态：已确认，进入实现

## 1. 问题

部分飞书客户端已提前注入 `tt.requestAuthCode`，但 `h5sdk.ready` 回调较晚或不触发，登录页面会先停留在授权加载状态。

## 2. 方案

- 检测到 `tt.requestAuthCode` 或兼容的 `tt.requestAccess` 已存在时，立即发起授权。
- 仅在授权方法尚未注入时，才使用 `h5sdk.ready` 等待 SDK 初始化。
- 保持单次授权启动保护和 8 秒总超时。

## 3. 验收标准

1. 飞书容器已注入授权方法时，点击后立即调用授权接口。
2. 授权方法尚未注入时，仍能通过 `h5sdk.ready` 初始化后调用。
3. 不重复调用授权接口，超时后不无限加载。
