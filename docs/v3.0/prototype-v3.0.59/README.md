# v3.0.59 项目预算与成本复核重构原型

本目录是“综合项目管理系统 v3.0.59 项目预算与成本复核重构”的开发前页面原型，不覆盖当前生产系统和旧版原型。

## 打开方式

直接打开：

```text
D:\myproject\docs\v3.0\prototype-v3.0.59\index.html
```

推荐重点查看：

- 工作台：负责人/员工双区、费用复核入口。
- 项目管理：项目大类/小类筛选，项目主信息与预算摘要，操作栏进入预算项。
- 项目预算项：项目管理操作栏进入，只维护当前项目预算金额、启停和备注，预算项金额合计即总预算。
- 项目详情：经营概况、预算项执行、合同与资金、成本组成。
- 项目合同：合同主信息与阶段分离，收入合同不填成本分类，支出合同按项目大类联动预算项和成本分类。
- 合同收款：选择收入合同阶段，复核通过后计入已收并核减应收。
- 合同付款：一级费用复核，复核通过即已付并计入合同成本。
- 项目费用：只保留项目、成本分类、金额、发生时间、附件和说明。
- 人工成本结转：财务按项目和月份录入，不限制同月多次录入。
- 费用复核：合同付款、项目费用、人工成本统一复核。
- 项目看板：按项目分类和成本大类展示预算执行。
- 基础配置：项目分类树、成本分类树。

## 设计口径

1. 合同付款复核通过即视为已付并计入项目合同成本。
2. 人工成本结转同一项目同一月份不限制录入次数。
3. 项目费用去掉收款方、银行账号和付款状态。
4. 研发项目小类为“自主研发”和“外部申报”。
5. 新增项目和项目主信息不再维护人天预算。
6. 人员成本菜单从新口径中移除，工时只累计天数，人工成本由财务月结录入并固定归入人工成本预算项。
7. 项目总成本分为人工成本和其他预算项成本；其他预算项成本由合同付款和项目费用产生。
8. 经营项目和研发项目的预算项模板只在后台基础配置维护；项目创建后自动生成该项目预算项。

这是开发前视觉确认稿。确认后，编码应按本原型和 `53-cost-budget-review-redesign-v3.0.59.md` 落地。
