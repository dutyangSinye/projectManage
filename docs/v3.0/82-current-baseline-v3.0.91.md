## 4. 当前关键业务口径

### 4.1 工时口径

- 工时单位固定为“天”，不展示小时。
- 工时天数按国家法定工作日历计算；调休工作日计入，法定假日不计入。
- 同一人员同一天不能填多条工时，不同项目也不允许重复。
- 工时开始日期与结束日期不能跨月。
- 项目类工时必须选择项目，项目范围由工时类型自动过滤：研发项目工时对应研发项目，技术服务工时对应经营项目。
- 非项目类工时不关联项目，也不显示项目阶段。
- 审批通过的工时计入项目已发生人天；草稿、审批中、驳回、撤回不计入。
- 预立项失败后的项目类工时可批量转为管理工时，记录原项目、转换时间、操作人和原因。

### 4.2 工时审批口径

- 研发项目工时、技术服务工时：项目负责人审批 → 项目审批人审批。
- 如果提交人正好是当前审批节点审批人，则转为提交人的直属上级审批。
- 观摩推广工时、市场营销工时：由基础配置中指定的市场部门负责人审批；负责人本人提交时转直属上级。
- 管理工时、其他工时：由提交人所属部门负责人审批；负责人本人提交时转直属上级。
- 直属上级优先来自飞书组织同步字段，系统中的手工配置可作为补充或覆盖。

### 4.3 项目与预算口径

- 当前预算项模板统一为 8 项：人工费用，材料、设备采购，水、电、燃气费用，委托、分包、外包费用，差旅费用，包装、运输费用，租赁费、折旧费，其他费用。
- 项目总预算 = 当前启用预算项预算金额之和。
- 人工成本结转固定归集到“人工费用”。
- 支出合同、合同付款、项目费用归集到所选预算项。
- 成本执行率按实际成本 / 总预算或预算项预算计算；预算为 0 时不显示为 0%。

### 4.4 合同与资金口径

- 收入合同不填写成本预算项；支出合同必须选择预算项。
- 合同、收款、付款、费用金额以“含税金额”为主，同时保存未税金额；未税金额允许手工维护，不强制按单一税率反算。
- 合同收款只关联收入合同和收入阶段；审批通过后增加已收、核减对应阶段剩余应收。
- 合同付款只关联支出合同和支出阶段；审批/复核通过后按当前流程写入项目成本或付款记录。
- 应收未收 = 已到期收入阶段剩余未收金额；未到期阶段不计入应收未收。
- 应付未付 = 已到期支出阶段剩余未付金额；未到期阶段不计入应付未付。
- 已收、已付只统计已确认且未冲销单据。
- 冲销不删除原记录，通过反向流水恢复阶段余额和看板口径。

### 4.5 费用与人工成本口径

- 项目费用、人工成本结转在未审批/未复核前可撤回。
- 项目费用附件不是必填。
- 费用复核通过即进入项目成本口径；人工成本结转复核通过后计入人工费用预算项。
- 后补人员成本时，历史已审批工时需要回算或补齐成本流水，避免看板漏算。

### 4.6 权限口径

- 权限由角色、菜单、操作和数据范围组成。
- 菜单权限控制页面可见性；操作权限控制新增、编辑、删除、审批、导入、导出、上传、下载、重试等按钮。
- 查询、重置筛选、分页、TAB 切换、展开/收起、关闭弹窗、返回上一页等普通界面动作不单独配置权限。
- 数据范围支持：仅本人、负责项目、本部门及下级、全部数据。
- 部门数据范围选择上级部门时包含所有下级部门。

## 5. 通知与提醒目录

当前系统内提醒、预警和飞书通知主要包括：

- 工时审批待办通知。
- 项目类二级审批下一节点通知。
- 非项目工时部门负责人审批通知。
- 工时填报定时提醒和 T-1 补漏提醒，按国家法定工作日历判断。
- 合同收款待审批、审批通过、驳回通知。
- 合同付款待审批、审批通过、驳回通知。
- 项目费用/人工成本结转费用复核待办、通过、驳回通知。
- 收付款阶段未来 30 天内到期提醒。
- 已到期未收/未付逾期提醒。
- 成本预算接近或超支预警。
- 人天预算接近或超支预警。
- 组织同步失败、通知发送失败和可重试通知。

通知策略在“系统管理 → 集成与通知”中维护，当前策略编辑为弹窗统一修改、统一保存。通知发送结果进入通知中心，可查看失败原因并重试。
