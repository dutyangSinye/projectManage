# 综合项目管理系统 v3.0.34：飞书首次登录用户引导

- 版本：v3.0.34
- 日期：2026-09-05
- 状态：已确认，进入实现

## 1. 问题

新服务器切换为真实飞书模式后，本地组织架构尚未完成同步时，OAuth 已经成功但本地用户表没有当前账号，登录被返回 `FEISHU_USER_NOT_SYNCED`，导致首位管理员无法完成初始化。

## 2. 方案

- 飞书 OAuth 认证成功后，先按 `open_id`、`user_id` 查找本地用户。
- 找不到时，使用飞书 OAuth 返回的用户标识、姓名和邮箱创建有效本地用户；部门暂为空，等待“集成与通知 → 同步组织架构”补齐组织信息。
- 已存在但停用的本地用户仍返回 `FEISHU_USER_INACTIVE`，不因登录自动恢复，避免绕过组织状态管理。
- 当前用户资料缺少稳定标识或姓名时，仍返回 `FEISHU_USER_NOT_SYNCED`，不创建不完整账号。
- 首次飞书登录管理员初始化在自动创建/找到用户后执行，持久化标记规则保持不变。

## 3. 受影响模块

- 后端飞书 OAuth 换取和本地用户绑定。
- 首次管理员初始化。
- 组织同步后的用户资料补全。

## 4. 验收标准

1. OAuth 成功且本地不存在当前用户时，可以创建有效用户并登录。
2. 无管理员配置时，首位成功登录用户成为系统管理员。
3. 重复登录不会重复创建用户或覆盖首位管理员。
4. 已存在停用用户仍不能登录。
5. 当前 OAuth 资料无稳定标识或姓名时，返回 `FEISHU_USER_NOT_SYNCED`。
6. 组织同步后，自动创建用户可按飞书标识更新部门、邮箱、姓名和组织状态。
