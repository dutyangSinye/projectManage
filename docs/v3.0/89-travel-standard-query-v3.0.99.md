# v3.0.99 差旅费标准查询入口

日期：2026-10-21
状态：已发布至 `116.169.217.29:8088`
类型：快速通道（独立查询页与工作台入口）

## 目标

- 将现有差旅标准查询单页纳入前端静态资源，随系统统一构建和部署。
- 在工作台页头提供所有已登录用户可见的“差旅费标准查询”入口。
- 提供稳定、可收藏和可直接分享的系统内 URL。

## 实现范围

- 页面文件：`frontend/public/travel.html`。
- 访问路径：`/travel.html`。
- 工作台入口在新标签页打开查询页，避免用户丢失当前工作台状态。
- 查询页保留出发地、目的地、员工职级、交换城市、查询结果和标准版本展示。
- 页面不调用后端接口，不读写系统业务数据，也不新增菜单权限。
- 对用户输入和动态结果进行 HTML 转义，避免查询内容作为 HTML 执行。

## 验收标准

1. 前端生产构建后，`dist/travel.html` 存在且可独立打开。
2. 工作台所有用户均可看到“差旅费标准查询”入口，点击后在新标签页打开 `/travel.html`。
3. 成都到北京、C 普通员工可正确查询里程、地区、交通、票价、住宿和补助标准。
4. 交换按钮和回车查询可用，未收录城市仍按既有规则推算。
5. 输入 HTML 标签时只作为文本显示，不执行脚本。
6. 桌面端与移动端无横向溢出，按钮和表单具备可见键盘焦点。
