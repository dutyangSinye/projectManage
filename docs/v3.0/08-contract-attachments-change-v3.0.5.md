# 合同附件功能变更说明

- 版本：v3.0.5
- 日期：2026-08-31
- 状态：已实现并部署验证

## v3.0.7 修订

合同附件预览体验调整：旧版 `.doc/.xls/.ppt` 通过后端无界面 LibreOffice 转换为 PDF 后预览；前端统一使用系统内预览弹窗，不再依赖新标签页弹窗。新版 Office 仍优先使用轻量 HTML 预览，转换预览失败时保留原文件下载能力。

## v3.0.8 修订

修复 NAS 发布流程遗漏后端 Dockerfile 的问题，Compose 改为使用随 `deploy` 目录发布的后端构建文件，确保 LibreOffice 预览依赖进入实际运行镜像；同时修复预览失败时错误兜底导致的 500。

后端镜像补充 CJK 字体，降低中文 Office 文件转换时的字体替换、换行和版式偏移。

## v3.0.6 修订

NAS 网关上传上限调整为 64MB，解决大于 1MB 的合同附件被 Nginx 拦截的问题；应用仍以 50MB 作为单文件业务上限。

## 目标

在新增合同和编辑合同流程中支持合同附件上传，并在合同详情中集中查看附件。附件由系统持久化保存，合同权限和项目数据权限沿用现有规则。

## 功能范围

1. 支持 `.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt`、`.pptx`，同时支持 PDF 和常见图片作为合同附件。
2. 附件保存原始文件名、类型、大小、上传人和时间；文件使用随机存储名，避免路径注入和同名覆盖。
3. `.docx`、`.xlsx`、`.pptx` 由服务端生成只读 HTML 预览，PDF 和图片使用浏览器内嵌预览；旧版 Office 二进制文件由 LibreOffice 转为 PDF 后预览，转换失败时提供下载兜底。
4. 新增合同先保存合同主数据，保存成功后在同一弹窗继续上传附件；编辑合同可保留、追加或删除附件。
5. 合同详情页展示附件列表，支持预览、下载和删除。删除附件需要合同管理权限。

## 接口契约

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/contracts/{contract_id}/attachments` | 查询合同附件 |
| POST | `/api/v1/contracts/{contract_id}/attachments` | 上传单个附件，multipart 字段 `file` |
| GET | `/api/v1/contract-attachments/{attachment_id}/preview` | 内嵌预览、Office HTML 预览或旧版 Office 转 PDF 预览 |
| GET | `/api/v1/contract-attachments/{attachment_id}/download` | 下载原文件 |
| DELETE | `/api/v1/contract-attachments/{attachment_id}` | 删除附件及存储文件 |

## 飞书集成边界

飞书可以作为后续的云端存储和协作入口，但通用 Office 预览地址、文件权限和应用授权依赖飞书租户配置，不能用一个未验证的 iframe 地址替代本地预览。本版本先完成系统内可靠预览和下载；后续接入飞书云盘时，可在附件记录增加飞书文件 token，并保留本地文件作为兜底。

## 验收标准

- 合同新增、编辑、详情三个入口均能看到附件状态。
- 未登录或无合同权限不能读写其他合同附件。
- 上传超限、非法扩展名、空文件均返回明确错误。
- Office 预览不执行上传文件中的脚本；旧版 Office 转换失败时不影响原文件下载。
- 后端编译、前端生产构建通过，合同列表、合同阶段、收付款合同选择回归正常。
