# 综合项目管理系统 v3.0.35：登录状态提示优化

- 版本：v3.0.35
- 日期：2026-09-05
- 状态：已确认，进入实现

## 1. 问题

用户直接访问系统或登录会话过期时，后端返回的 `AUTH_REQUIRED` 被前端原样展示，容易被误解为系统故障。

## 2. 方案

- 保留后端 401 和登录保护逻辑。
- 前端将 `AUTH_REQUIRED` 转换为“请使用飞书账号登录后继续”。
- 飞书 OAuth 失败、用户未同步、用户停用等业务错误继续使用对应的明确提示。

## 3. 验收标准

1. 未登录访问系统时不再展示 `AUTH_REQUIRED` 原始代码。
2. 页面仍展示“使用飞书登录”按钮。
3. 真实飞书登录成功后可以正常进入系统。
4. 其他错误码不被误转为登录提示。
