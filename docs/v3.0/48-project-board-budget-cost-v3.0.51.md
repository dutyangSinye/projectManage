# v3.0.51 项目看板补齐预算与成本展示

- 日期：2026-09-07
- 版本：v3.0.51
- 模式：快速迭代

## 1. 问题

项目看板原先只返回合同额、已收、已付、应收、应付和现金口径毛利，缺少设计文档已要求的人员成本、项目费用、人天预算、成本预算和费用预算等经营指标。

## 2. 修改内容

1. 项目看板接口每行补充：
   - 人天预算、已发生人天、人天执行率；
   - 成本预算、实际总成本、剩余成本、成本预算执行率；
   - 人员成本、支出合同实际成本、项目费用；
   - 费用预算、费用预算剩余、费用预算使用率；
   - 人天执行状态和成本执行状态。
2. 页面“项目经营汇总”下方新增预算与成本 KPI：人天预算执行、人员成本、项目费用、实际总成本、成本预算执行率、费用预算使用率。
3. 项目明细表新增“人天、人员成本、项目费用”三列，点击项目仍可进入完整项目详情。
4. 看板 CSV 导出同步增加上述预算与成本字段。

## 3. 口径

- 已发生人天仅统计已审批工时。
- 人员成本取项目人员成本流水，按审批时单价快照。
- 项目费用取已审批项目费用流水，扣除费用冲销。
- 实际总成本 = 人员成本 + 已审批支出合同付款 + 已审批项目费用。
- 各预算执行率未配置预算时返回空值，页面显示“—”。

## 4. 验收标准

1. 项目看板汇总和明细可见人天预算、人员成本、项目费用和费用预算。
2. 未配置预算的项目不报错，执行率显示为“—”。
3. 导出 CSV 包含新增预算与成本列。
4. 前端生产构建和后端全量回归通过。
