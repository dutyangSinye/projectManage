# 综合项目管理系统 v3.0.41：飞书登录会话保持

- 版本：v3.0.41
- 日期：2026-09-05
- 状态：已确认，进入实现

## 1. 问题

新服务器日志显示飞书授权换码接口返回 200，但随后读取当前用户接口返回 401。授权码本身有效，问题在于浏览器请求未明确携带后端签发的 Session Cookie。

## 2. 方案

- 前端统一 API 请求显式设置 `credentials: "include"`。
- 保持 Nginx 前后端同源访问和后端现有 SessionMiddleware 配置。
- 不修改飞书授权码换取、用户同步、权限和业务数据逻辑。

## 3. 验收标准

1. `/api/v1/auth/feishu/exchange` 返回 200 后，后续 `/api/v1/me` 返回当前用户而不是 401。
2. 登录后刷新页面仍保持登录状态。
3. 登出后 Session Cookie 被清除，重新访问需要登录。
4. 普通 API、附件上传和下载请求不受影响。
