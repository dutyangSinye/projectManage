- 版本：v3.0.59 设计稿
- 日期：2026-09-08
- 状态：关键业务口径已确认，页面原型已生成，待确认，未开发
- 来源：`C:\Users\Admin\Desktop\系统修改内容.docx`
- 适用系统：综合项目管理系统
- 页面原型：`docs/v3.0/prototype-v3.0.59/index.html`

## 1. 设计结论

本次重构的核心方向是把项目经营管理从“按几个固定字段累计金额”改成“按项目分类、预算明细、成本分类和一级复核单据驱动”。旧版中动态多级费用审批、人员单天成本、费用类型拆分和项目表内固定预算字段都会被收敛。

重构后的系统保持四大模块结构不变，但项目管理内部发生以下变化：

1. 项目类型改为两级结构：项目大类和项目小类。
2. 项目预算从项目主表字段中拆出，改为“按项目大类配置的预算项体系”。
3. 经营项目和研发项目分别维护预算项模板，两套预算项可以重叠，也可以各自专属。
4. 成本分类改为成本大类和成本小类两级，由基础配置维护，并由预算项关联到成本分类。
5. 支出合同必须选择预算项，系统根据所选项目大类联动可选预算项和成本分类，合同付款审批通过后按该预算项计入成本。
6. 合同付款和项目费用取消现有动态多级工作流，改为一级“费用复核”。
7. 项目费用不再区分差旅费、无合同发票、其他费用，统一按项目、预算项、金额、发生时间和附件提交复核。
8. 去掉“人员成本”按人员单天成本维护功能，改为财务每月按项目填报人工成本，一级复核通过后固定计入“人工成本”预算项。
9. 项目管理、项目详情和项目看板中的收入、成本、预算、毛利都按新口径重算；预算以预算项为主，成本分类用于归集、明细和追溯。

这是一轮核心经营口径调整，不建议边写边改。建议先确认本文档，再做页面原型，最后编码和发布。

## 2. 业务目标

### 2.1 要解决的问题

当前系统已经能管理项目、合同、收付款、费用、工时和看板，但成本口径越来越复杂：

- 项目预算分散在项目主表里，只能维护人天预算、项目成本预算和费用预算三个固定值。
- 费用被拆成差旅、无合同发票和其他费用，页面重、审批重，和用户现在希望的财务录入方式不一致。
- 人员成本按人员单天成本和工时自动计算，遇到财务月结后成本口径时反而不够准确。
- 项目看板里既要看大类，也要能追溯小类，但当前缺少统一成本分类。
- 付款和费用动态多级审批过重，和当前“费用复核人一级审批”的使用方式不一致。

### 2.2 本次目标

1. 用项目大类下的预算项模板支撑经营项目和研发项目的不同预算结构。
2. 用独立预算项表承载项目总预算，预算项金额合计即项目总预算。
3. 简化合同付款、项目费用、人工成本的审批流程，统一为一级费用复核。
4. 保留项目经营分析能力，但让概况看大类、明细查小类。
5. 移除人员单天成本维护，避免历史工时因后补人员成本而反复回算。

### 2.3 本次不做

- 不接入完整财务总账、凭证、税务、工资或银行付款系统。
- 不再维护差旅明细字段、发票专属字段、无合同付款专属流程。
- 不再使用合同付款和项目费用的多级动态审批工作流。
- 不做成本生效日期、人员单天成本、按员工维度自动折算人工成本。
- 不做项目看板小类总览，概况层只到成本大类，小类在明细里看。

项目详情和项目看板中，项目大类用于一级筛选和统计分组，项目小类用于项目明细分析。

## 5. 项目预算项设计

### 5.1 为什么改为预算项

项目主表只适合保存项目名称、编号、状态、负责人、部门、客户和是否允许工时填报等主信息。预算不再放在项目新增和项目主信息里维护，也不再单独维护“人天预算、项目成本预算、费用预算”几个固定字段。

新口径下，项目预算由“预算项”构成：

```text
项目总预算 = 当前项目启用的预算项预算金额合计
```

预算项由项目大类决定。经营项目和研发项目分别维护自己的预算项模板。两套模板可以存在同名预算项，例如人工成本；也可以存在专属预算项，例如经营项目的工程分包成本、研发项目的测试试验费。

### 5.2 项目大类预算项模板

经营项目预算项默认建议：

| 预算项 | 关联成本大类 | 关联成本小类 | 发生来源 |
| --- | --- | --- | --- |
| 人工成本 | 人工成本 | 人工成本 | 人工成本结转 |
| 材料成本 | 材料成本 | 材料成本 | 支出合同付款、项目费用 |
| 设备采购 | 设备采购 | 设备采购 | 支出合同付款 |
| 技术服务费 | 其他直接/间接费用 | 技术服务费 | 支出合同付款、项目费用 |
| 运输包装费 | 其他直接/间接费用 | 运输、包装费 | 项目费用 |
| 工程分包成本 | 加工成本、工程分包成本 | 工程分包成本 | 支出合同付款 |

研发项目预算项默认建议：

| 预算项 | 关联成本大类 | 关联成本小类 | 发生来源 |
| --- | --- | --- | --- |
| 人工成本 | 人工成本 | 人工成本 | 人工成本结转 |
| 材料成本 | 材料成本 | 材料成本 | 支出合同付款、项目费用 |
| 测试试验费 | 其他直接/间接费用 | 检测试验费 | 项目费用 |
| 外部加工费 | 加工成本、工程分包成本 | 外部加工费 | 支出合同付款 |
| 设备采购 | 设备采购 | 设备采购 | 支出合同付款 |

以上只是初始化模板，后续只能在后台“基础配置”中维护。经营项目和研发项目必须单独配置预算项模板，不能混用同一套模板。项目详情和项目操作栏中的“预算项”页面不维护模板，只维护当前项目复制出来的预算金额、启用状态和备注。

### 5.3 项目预算项字段

建议新增或重构为 `project_budget_items`：

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `project_id` | 所属项目 |
| `project_major_category` | 项目大类快照，便于校验预算项模板 |
| `template_id` | 来源模板项，用于追溯该预算项来自后台哪一条模板 |
| `budget_item_code` | 预算项编码 |
| `budget_item_name` | 预算项名称 |
| `cost_major_id` | 关联成本大类 |
| `cost_minor_id` | 关联成本小类；如一项对应多个小类，可使用映射表 |
| `budget_amount` | 预算金额 |
| `sort_order` | 排序 |
| `enabled` | 是否启用 |
| `remark` | 预算说明 |
| `created_by` / `updated_by` | 操作人 |
| `created_at` / `updated_at` | 时间 |

如果预算项需要对应多个成本小类，例如“运输包装费”同时覆盖运输、包装费，建议增加 `project_budget_item_cost_mappings`，保存预算项和成本小类的多对多关系。

### 5.4 预算项维护入口

项目新增和项目主信息编辑不再展示人天预算、项目成本预算和费用预算。项目保存成功后，系统根据项目大类自动从后台模板生成该项目的预算项。

项目管理列表操作栏增加“预算项”按钮，点击进入该项目的预算项维护页面。该页面只处理“当前项目”的预算金额，不处理经营/研发模板配置。

预算项页面展示：

```text
项目预算项

项目：智慧工地机器人协同平台
项目大类：经营项目
预算来源：后台经营项目预算项模板自动生成

预算项              预算金额     已发生金额     剩余金额     使用率     来源
人工成本            90,000       36,000        54,000      40.0%      人工成本结转
材料成本            120,000      38,000        82,000      31.7%      合同付款/项目费用
设备采购            300,000      285,000       15,000      95.0%      支出合同付款
技术服务费          70,000       0             70,000      0.0%       合同付款/项目费用

[调整预算金额] [导入项目预算金额] [查看后台模板配置]
```

项目预算项页面允许：

1. 修改当前项目某个预算项的预算金额。
2. 启用或停用当前项目某个预算项。
3. 填写当前项目预算项备注。
4. 导入当前项目预算金额。

项目预算项页面不允许：

1. 新增经营/研发模板项。
2. 修改预算项名称、编码和成本分类映射。
3. 把经营项目模板项混入研发项目，或把研发项目模板项混入经营项目。

### 5.5 预算项与成本发生关系

1. 人工成本结转单固定归入“人工成本”预算项。
2. 支出合同创建时选择预算项，系统根据项目大类筛选可选预算项，并带出预算项关联的成本大类/小类。收入合同不展示也不保存成本分类。
3. 合同付款审批通过后，按支出合同上的预算项计入该预算项已发生金额。
4. 项目费用填报时选择预算项，系统带出预算项关联的成本大类/小类，复核通过后计入该预算项已发生金额。
5. 项目工时只累计工时天数，不参与预算金额计算。

项目详情和项目看板中的预算、成本、预算剩余和使用率均按预算项汇总，不再引用旧字段。

## 6. 合同模块重设计

### 6.1 收入合同

收入合同仍然用于形成项目合同收入、收款阶段、应收、已收和收入合同执行情况。收入合同不需要选择预算项，也不需要选择成本大类或成本小类。

保留字段：

- 项目
- 合同名称
- 合同编号
- 客户
- 合同金额
- 签订日期
- 合同周期
- 收款阶段
- 附件
- 状态

### 6.2 支出合同

支出合同新增预算项和成本分类字段：

- 预算项
- 成本大类
- 成本小类

支出合同的预算项必须根据所选项目的大类动态联动：

```text
选择项目 → 得到项目大类 → 加载该大类预算项 → 选择预算项 → 带出成本大类/小类
```

支出合同付款审批通过后，系统按合同上的预算项和成本分类写入项目成本流水。合同详情、付款单详情、项目详情和项目看板均展示该预算项和成本分类。

支出合同保留字段：

- 项目
- 合同名称
- 合同编号
- 供应商
- 合同金额
- 预算项
- 成本大类
- 成本小类
- 签订日期
- 合同周期
- 付款阶段
- 附件
- 状态

### 6.3 合同详情页面

合同详情重新分为四块：

```text
合同详情
1. 合同主信息：项目、合同类型、往来单位、金额、状态、签订日期
2. 预算与成本归集：支出合同展示预算项、成本大类/小类，收入合同不展示
3. 阶段计划：收入合同展示收款阶段，支出合同展示付款阶段
4. 附件和操作记录
```

点击合同名称进入详情；阶段列表默认只读展示，新增阶段必须点击“新增阶段”打开弹窗，避免旧版点击阶段区域时误以为正在新增。

## 7. 合同收款和合同付款重设计

### 7.1 合同收款

合同收款继续关联收入合同和收入阶段。审批保持一级复核，审批通过后计入项目已收，并核减应收。

口径：

```text
已收 = 审批通过的合同收款单金额 - 冲销金额
应收未收 = 已到期收入阶段计划金额 - 该阶段已审批收款金额
```

### 7.2 合同付款

合同付款取消当前动态多级工作流，改为一级费用复核。

表单保留：

- 项目
- 支出合同
- 付款阶段
- 付款金额
- 付款日期
- 收款方名称
- 收款银行
- 收款账号
- 预算项和成本分类快照，由支出合同带出
- 附件
- 备注

系统从支出合同带出供应商、合同阶段、预算项和成本分类；从供应商带出默认银行账户，允许在单据上修改并保存快照。

审批通过后：

```text
合同成本 = 审批通过的合同付款金额
已付 = 审批通过的合同付款金额
应付未付 = 已到期支出阶段计划金额 - 该阶段已审批付款金额
```

如果未来仍要区分“已确认成本”和“实际支付”，可以在付款单上再增加支付确认状态；本轮按文档要求，一级复核通过即计入成本和已付。

### 7.3 费用复核岗位

合同付款的审批人来自系统管理中的“费用复核”审批岗位。岗位内可配置多人，任意一人审批通过即可完成。

审批结果记录实际审批人姓名，飞书通知发送给费用复核岗位所有有效成员。任一成员审批后，其他人的待办关闭。

## 8. 项目费用重设计

### 8.1 模块定位

项目费用不再区分差旅费、无合同发票、其他费用，也不再走动态多级审批。它变成一个通用的项目成本录入单。

项目费用只负责记录项目发生的一笔非合同成本，审批通过后计入项目费用和项目总成本。

### 8.2 表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 项目 | 是 | 从可见项目中选择 |
| 预算项 | 是 | 根据项目大类读取预算项模板 |
| 成本大类 | 自动/只读 | 由预算项带出 |
| 成本小类 | 自动/只读 | 由预算项带出；预算项映射多个小类时可在该范围内选择 |
| 金额 | 是 | 大于 0，人民币，两位小数 |
| 发生时间 | 是 | 业务发生日期 |
| 附件 | 是 | 凭证、说明材料或财务依据 |
| 说明 | 否 | 补充费用来源和原因 |

不再展示：

- 差旅开始/结束日期
- 出发地/目的地
- 发票代码/发票号码
- 是否需要支付
- 收款方姓名、银行、账号
- 付款到期日
- 多级审批路径预览

### 8.3 状态

```text
草稿 DRAFT
  → 提交复核 PENDING_REVIEW
  → 复核通过 APPROVED
  → 复核驳回 REJECTED
  → 冲销 REVERSED
```

草稿和驳回允许申请人或有权限管理员修改；复核中只读；已通过不允许直接修改，只能冲销。

### 8.4 计入口径

```text
项目费用 = 审批通过且未冲销的项目费用单金额
项目总成本 = 合同成本 + 项目费用 + 人工成本
```

项目费用按预算项汇总展示，成本大类和成本小类用于明细追溯。

## 9. 人工成本重设计

### 9.1 去掉旧功能

删除或隐藏现有“人员成本”菜单。旧功能中的人员单天成本、按工时自动生成成本快照、人员成本回算逻辑全部停止使用。

工时审批通过后只影响：

- 已发生人天
- 工时看板
- 项目工时明细

工时不再自动生成项目人工成本。

### 9.2 新增人工成本录入

财务每月结账后，根据内部核算结果按项目录入人工成本。人工成本录入和项目费用使用同样的一级费用复核。

建议页面名称：人工成本结转。

字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 项目 | 是 | 选择项目 |
| 核算月份 | 是 | 例如 2026-09 |
| 预算项 | 自动 | 固定为人工成本预算项 |
| 成本大类 | 自动 | 固定为人工成本 |
| 成本小类 | 自动 | 固定为人工成本 |
| 金额 | 是 | 财务核算后的人工成本金额 |
| 附件 | 是 | 成本分摊表或财务月结依据 |
| 说明 | 否 | 分摊口径说明 |

审批通过后计入项目人工成本，并归入该项目的“人工成本”预算项。一个项目同一核算月份不限制录入次数，财务可以按部门、批次或成本分摊来源分多笔录入。系统在录入时提示该项目该月份已有人工成本记录，但不阻止保存和提交。

### 9.3 与工时的关系

工时仍然保留。人天用于项目投入进度和工作量分析，人工成本来自财务月结录入。

```text
已发生人天 = 已审批工时天数
人工成本 = 已审批人工成本结转单金额
人天单价分析 = 人工成本 / 已发生人天
```

人天单价只作为分析指标，不作为成本生成依据。

## 10. 项目经营口径

### 10.1 收入

```text
合同收入 = 收入合同金额合计
已收 = 审批通过的合同收款单金额合计 - 收款冲销
应收未收 = 已到期收入阶段金额 - 对应阶段已审批收款金额
```

### 10.2 成本

```text
合同成本 = 审批通过的合同付款单金额合计 - 付款冲销
项目费用 = 审批通过的项目费用单金额合计 - 费用冲销
人工成本 = 审批通过的人工成本结转单金额合计 - 人工成本冲销
实际总成本 = 合同成本 + 项目费用 + 人工成本
```

项目成本分为两层：

```text
第一层：人工成本、其他预算项成本
第二层：按预算项展开，如材料成本、设备采购、技术服务费、测试试验费等
```

其中，人工成本只来自人工成本结转；其他预算项成本来自支出合同付款和项目费用。

### 10.3 预算

```text
项目总预算 = 当前项目启用预算项的预算金额合计
预算项已发生 = 归属该预算项的合同付款 + 项目费用 + 人工成本结转 - 冲销金额
预算项剩余 = 预算项预算金额 - 预算项已发生
项目预算剩余 = 项目总预算 - 实际总成本
总预算使用率 = 实际总成本 / 项目总预算
预算项使用率 = 预算项已发生 / 预算项预算金额
```

工时天数不参与项目预算金额计算。工时仍用于工时看板、人员投入分析和项目工时明细。

### 10.4 毛利

```text
项目毛利 = 已收 - 实际总成本
项目毛利率 = 项目毛利 / 已收
预计毛利 = 合同收入 - 项目总预算
预计毛利率 = 预计毛利 / 合同收入
```

当已收为 0 时，不展示实际毛利率，避免除零产生误导。

## 16. 迁移设计

### 16.1 项目分类迁移

旧项目类型映射建议：

| 旧值 | 新项目大类 | 新项目小类 |
| --- | --- | --- |
| `RND_PROJECT` 研发项目 | 研发项目 | 自主研发 |
| `TOPIC_PROJECT` 课题项目 | 研发项目 | 外部申报 |
| `IMPLEMENTATION_PROJECT` 实施项目 | 经营项目 | 技术服务 |
| `DEMONSTRATION_PROJECT` 观摩项目 | 经营项目 | 技术服务 |

如果迁移时遇到无法识别旧值，放入“经营项目 / 技术服务”，并在迁移报告中列出供人工修正。

### 16.2 预算迁移

旧字段迁移：

| 旧字段 | 新位置 |
| --- | --- |
| `budget_days` | 项目预算表 `MAN_DAY` |
| `budget_cost` | 项目预算表一条总成本预算，成本大类暂放“其他直接/间接费用 / 其他”或等待人工拆分 |
| `expense_budget` | 不再单独迁移为字段；如有值，生成“其他直接/间接费用 / 其他”的成本预算备注 |

考虑当前生产业务数据已清空，实际迁移压力较小；但迁移脚本仍应幂等，避免测试环境残留数据报错。

### 16.3 人员成本迁移

旧人员单天成本数据不删除，先保留字段和历史表，但页面隐藏、计算停用。旧审批工时生成的人员成本流水如果存在，不再参与新项目成本口径，除非管理员执行历史数据转换。

当前线上业务数据已清空，首期可以不提供历史转换工具。

### 16.4 工作流迁移

新单据不再使用动态工作流定义。旧 `workflow_*` 表保留，避免破坏历史详情；新提交的合同付款、项目费用、人工成本只生成一级复核任务。

如果系统中仍有运行中的旧流程单据，迁移前必须先处理完或由管理员作废。当前生产业务数据已清空，可以直接切换。

## 17. 验收标准

### 17.1 基础配置

- 项目大类、小类可以维护，项目新增和筛选能联动。
- 成本大类、小类可以维护，所有成本录入页面能联动。
- 经营项目和研发项目可以在后台基础配置中分别维护预算项模板。
- 预算项可以关联一个或多个成本分类。
- 没有成本小类的大类能自动生成同名小类，不要求用户重复选择。

### 17.2 项目预算项

- 项目新增不再要求填写人天预算、项目成本预算和费用预算。
- 项目保存成功后，系统按项目大类自动生成该项目的预算项。
- 项目管理操作栏有“预算项”按钮，可以进入该项目预算项维护页面。
- 经营项目只能初始化和选择经营项目预算项模板，研发项目只能初始化和选择研发项目预算项模板。
- 项目预算项页面只能查看和维护当前项目的预算金额、启用状态、备注、已发生、剩余和使用率。
- 项目预算项页面不能修改经营/研发模板结构；模板结构只能在后台基础配置维护。
- 项目总预算等于该项目启用预算项金额合计。
- 项目列表、项目详情和项目看板能实时显示总预算、实际总成本、预算剩余和总预算使用率。

### 17.3 合同和付款

- 支出合同必须选择成本大类和成本小类。
- 支出合同必须先选择预算项，再由预算项带出成本大类和成本小类。
- 支出合同的预算项必须按所选项目大类动态筛选。
- 收入合同不展示、不填写、不保存预算项和成本分类。
- 合同付款提交后只进入一级费用复核。
- 费用复核岗位所有成员收到飞书通知。
- 任一复核人通过后，付款计入合同成本和已付，并记录实际复核人。
- 驳回后不计入成本和已付。

### 17.4 项目费用

- 项目费用新增页面只保留项目、预算项、金额、发生时间、附件和说明；成本大类和小类由预算项联动。
- 项目费用不再出现差旅、发票、收款账户、多级审批等字段。
- 复核通过后按预算项和成本分类计入项目费用和总成本。

### 17.5 人工成本

- 人员成本菜单不再显示。
- 工时审批通过不再生成金额成本，只累计已发生人天。
- 财务可以按项目和月份录入人工成本，复核通过后计入项目人工成本。
- 人工成本结转固定归入“人工成本”预算项。
- 项目详情能展示人工成本、工时天数和人均成本分析，但工时天数不作为预算金额。

### 17.6 项目看板

- 项目看板能按项目大类、小类、部门、负责人筛选。
- 看板按预算项展示预算、已发生、剩余和使用率。
- 看板固定拆分人工成本和其他预算项成本。
- 点击预算项可以下钻到对应合同付款、项目费用和人工成本结转明细。
- 毛利、毛利率、总预算使用率不再引用旧费用预算字段和人天预算字段。

## 19. 主要风险与控制

| 风险 | 控制 |
| --- | --- |
| 旧成本字段和新预算表同时存在，口径混乱 | 页面和接口统一从预算表/流水汇总，旧字段只保留兼容不展示 |
| 人工成本不再由工时自动计算后，用户误以为工时不计入项目 | 页面明确“工时计人天，人工成本由财务月结录入” |
| 合同付款一级复核后少了多级审批控制 | 费用复核岗位可配置多人，飞书通知全员，任一人审批留痕 |
| 成本小类过多导致项目看板拥挤 | 看板只展示大类，小类进入明细 |
| 预算拆分后首次录入工作量增加 | 提供预算导入模板，并支持项目详情中快速新增预算项 |
| 停用旧工作流导致历史单据打不开 | 旧 `workflow_*` 表保留只读兼容，新单据不用旧流程 |

## 20. 已确认开发口径

以下内容已按 2026-09-08 确认结果固化，后续原型和编码以此为准：

1. 合同付款复核通过即视为已付并计入项目合同成本，不再单独设置出纳支付确认。
2. 人工成本结转不限制同一项目同一月份的录入次数。
3. 项目费用彻底去掉收款方、银行账号和付款状态，只作为项目成本录入凭证。
4. 研发项目小类为“自主研发”和“外部申报”。
5. 新增项目和项目详情主信息中去掉人天预算，项目总预算改为项目预算项金额合计。
6. 经营项目和研发项目分别维护预算项模板，预算项可以重叠，也可以各自专属。
7. 人工成本结转固定归入“人工费用”预算项。
8. 项目总成本分为人工成本和其他预算项成本；其他预算项成本由合同付款和项目费用发生。
9. 收入合同不填写成本分类；支出合同按项目大类动态联动预算项和成本分类。
10. 经营项目和研发项目的预算项模板只在后台基础配置维护；项目创建后自动生成该项目预算项。

## 21. 页面原型

页面原型已生成到：

```text
docs/v3.0/prototype-v3.0.59/index.html
```

本次原型不覆盖当前生产系统，也不覆盖 `docs/v3.0/prototype/` 历史原型。它用于 v3.0.59 开发前视觉与交互确认。

### 21.1 原型覆盖页面

| 页面 | 设计重点 |
| --- | --- |
| 工作台 | 保留负责人和员工双区结构，突出项目经营账本、待费用复核、预算预警和个人工时入口 |
| 项目管理 | 项目大类/小类、部门、负责人、状态和标题筛选；列表只展示项目主信息和预算摘要 |
| 项目预算项 | 项目管理操作栏进入，只维护当前项目预算金额、启停和备注，不维护模板结构 |
| 项目详情 | 经营概况、预算项执行、合同与资金、成本组成统一按新口径展示 |
| 项目合同 | 合同主信息与阶段分离；收入合同不填成本分类，支出合同按项目大类联动预算项和成本分类 |
| 合同详情 | 直接展示合同金额、已结算、到期未结、结算率和款单笔数，阶段列表铺开 |
| 合同收款 | 选择收入合同阶段，复核通过后计入已收并核减已到期应收 |
| 合同付款 | 一级费用复核，复核通过即已付并计入合同成本 |
| 项目费用 | 简化为项目、成本大类/小类、金额、发生时间、附件和说明 |
| 人工成本结转 | 财务按项目和月份录入人工成本，同项目同月允许多次录入并提示历史记录 |
| 费用复核 | 合同付款、项目费用和人工成本统一待复核入口 |
| 项目看板 | 按项目大类、小类、部门、负责人筛选，按成本大类展示预算、发生、剩余和使用率 |
| 基础配置 | 项目分类树和成本分类树，替代旧静态扁平下拉 |

### 21.2 视觉方向

原型沿用当前系统浅色办公风，不引入 Element Plus。为了让本轮“项目预算和成本复核”有清晰识别，新增一个“成本账本式”视觉元素：

- 用浅账簿底色承载经营摘要，不做深色大屏。
- 用预算执行尺展示预算项的预算、已发生、剩余和使用率。
- 用复核单据卡把合同付款、项目费用和人工成本合并到同一个处理入口。
- 表格继续保持紧凑办公风，避免项目管理和看板出现横向滚动依赖。

### 21.3 编码边界

原型确认前不进入编码。确认后编码必须以本文档和该原型为基准，尤其要保证以下内容不能回退：

1. 项目费用不再出现收款方、银行账号、付款状态。
2. 人工成本不再由工时自动折算。
3. 费用类单据不再走动态多级审批。
4. 支出合同、合同付款、项目费用和人工成本都必须落到预算项和成本大类/小类。
5. 项目看板和项目详情的成本、预算、毛利口径必须统一来自预算项和项目流水。
6. 项目新增和项目详情主信息不能再出现人天预算字段。
7. 预算项模板配置入口只能出现在后台基础配置，不出现在项目详情或项目预算项页面。
