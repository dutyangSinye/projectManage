- 日期：2026-09-07

## 1. 新流程

### 1.1 差旅费用审批

经办人提交 → 项目负责人审批 → 会计审批 → 上级领导审批 → 财务总监审批 → 总经理审批 → 出纳支付。

适用单据：`PROJECT_EXPENSE_TRAVEL`。

### 1.2 合同付款与费用审批

经办人提交 → 项目负责人审批 → 会计审批 → 经营审批 → 上级领导审批 → 经营副总审批 → 财务总监审批 → 总经理审批 → 出纳支付。

适用单据：`PAYMENT`、`PROJECT_EXPENSE_INVOICE`、`PROJECT_EXPENSE_OTHER`，即合同付款、费用付款和无合同发票/其他报销统一走此流程。

## 2. 岗位调整

- 新增审批岗位：财务总监。
- 差旅流程调整节点顺序，末尾保留出纳支付。
- 费用与付款统一流程末尾保留出纳支付。
- 新版本只影响之后提交的新单据；已提交单据继续按提交时的流程快照流转。
