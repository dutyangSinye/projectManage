# v3.0.96 工时月度台账打印说明

## 背景

月度台账已支持按项目汇总和查看明细，但项目负责人需要把某项目某月已审批工时按人员汇总打印留档。原型确认后，本次在“工时管理 → 工时台账 → 月度台账”补充项目维度打印能力。

## 功能范围

- 月度台账每个项目汇总行新增“打印”操作。
- 点击后打开打印预览弹窗，展示：
  - 项目名称
  - 年月
  - 项目负责人
  - 序号
  - 人员
  - 工时合计
- 打印数据只统计所选项目、所选月份内状态为“已通过 / 已锁定”的工时。
- 打印表按人员汇总工时，不展示底部签字区，不展示备注列。

## 接口设计

新增接口：

```http
GET /api/v1/worklogs/monthly-ledger/{project_id}/print?month=YYYY-MM
```

返回字段：

- `month`：统计月份
- `project_id` / `project_name`：项目信息
- `project_owner_name`：项目负责人
- `printed_by_name` / `printed_at`：打印人和生成时间
- `rows`：人员汇总行，包含序号、人员和工时合计
- `total_quantity`：项目本月已审批工时总计

## 验收口径

1. 月度台账项目行可点击“打印”。
2. 预览弹窗内容与确认后的原型一致，不包含“项目负责人确认 / 部门负责人确认 / 备注”。
3. 打印只包含已审批工时，审批中、草稿、驳回工时不计入打印表。
4. 后端编译、迁移回归和前端生产构建通过后发布。
