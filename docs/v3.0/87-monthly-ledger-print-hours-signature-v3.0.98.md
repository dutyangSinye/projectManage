# v3.0.98 工时月度台账打印版式调整

日期：2026-10-19
状态：已确认执行
类型：快速通道（打印版式与展示口径调整）

## 1. 需求

- 打印纸面去掉系统内部痕迹，包括审批口径说明、系统名称、打印人和生成时间。
- 打印表中的工时由“天”换算为“小时”，固定按 `1 天 = 8 小时` 计算。
- 表格下方增加“项目负责人”和“考勤员”两个手写签字栏。

## 2. 实现范围

- 仅调整“工时管理 → 月度台账 → 打印”的纸面展示，不改变月度台账页面、明细、导出文件和后端统计口径。
- 打印接口继续返回按天统计的数据；前端打印层统一乘以 8，避免改变其他功能对原字段的使用。
- 数据仍来源于当前项目、当前月份内已通过或已锁定的工时，但打印纸面不显示审批相关文案。

## 3. 打印字段

- 标题：项目月度工时汇总表。
- 基本信息：项目名称、年月、项目负责人、工时合计（小时）。
- 人员汇总：序号、人员、工时合计（小时）。
- 签字栏：项目负责人、考勤员。

## 4. 关联回归

- 月度台账汇总和明细仍按天展示。
- 月度台账 CSV 导出字段和单位不变。
- 打印预览与浏览器实际打印均只显示打印纸面，按钮和弹窗工具栏不进入纸张。
- A4 纸面无横向溢出，签字栏不会与表格重叠。

## 5. 验收标准

1. 打印纸面不出现“审批”“综合项目管理系统”“打印人”“生成时间”等字样。
2. 原 `5 天` 显示为 `40 小时`，`12 天` 显示为 `96 小时`，所有人员及总计均按相同规则换算。
3. 表格下方有“项目负责人”和“考勤员”两个可手写签字区域。
4. 非打印页面的月度台账统计与导出不受影响。

## 6. 验证结果

- 前端生产构建：通过（`tsc -b && vite build`，564 个模块）。
- 后端关联回归：通过（`backend/tests/test_v3_migration.py`，46 项通过；2 条既有 FastAPI 生命周期弃用警告）。
- 浏览器实测：`2.5 天` 正确显示为 `20 小时`；人员小计和总计一致。
- 纸面文案检查：未出现“审批”“综合项目管理系统”“打印人”“生成时间”。
- 布局检查：打印纸面无横向溢出；签字栏位于表格下方，无重叠。
