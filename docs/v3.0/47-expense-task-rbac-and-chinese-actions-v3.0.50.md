# v3.0.50 费用审批任务授权与中文审批记录

- 日期：2026-09-07
- 版本：v3.0.50
- 模式：快速迭代

## 1. 问题

1. 项目费用流程的任务已正确分配给项目审批人，但只有拥有“项目费用 - 审批”菜单权限的用户才能查询自己的待办、打开费用详情并审批。樊公海、林宗奇等由流程动态指派的人员没有该菜单权限时，系统里看不到待审批任务，审批接口也会返回无权限。
2. 项目费用详情“审批记录”展示的是 `SUBMIT`、`APPROVE`、`REJECT`、`CONFIRM_PAYMENT` 等英文操作，不符合中文界面要求。

## 2. 修改规则

1. 费用流程任务按“当前登录用户是否被指派该任务”授权：
   - 待办任务列表只返回指派给当前用户的流程任务，不再要求“项目费用 - 审批”权限。
   - 通过、驳回、确认支付只校验任务是否指派给当前用户且处于待处理状态，不再要求菜单权限。
2. 项目费用详情“审批记录”返回中文动作：
   - `SUBMIT` -> 提交审批
   - `APPROVE` -> 节点通过
   - `AUTO_APPROVE` -> 系统自动通过
   - `REJECT` -> 审批驳回
   - `CONFIRM_PAYMENT` -> 出纳确认支付
   - `WITHDRAW` -> 撤回申请
3. 未命名流程动作仍保留原值回显，避免把未知动作错误翻译。

## 3. 验收标准

1. 只有普通员工权限、但被流程指派为审批人的用户，可在费用页看到自己的待审批任务并完成审批。
2. 审批完成后流程正常进入下一节点。
3. 项目费用详情审批记录全部为中文动作。
4. 原有“项目费用 - 审批”权限仍然可用，不影响管理员授权场景。
5. 前端生产构建、后端全量回归通过。

## 4. 通知核查结论

- 2026-09-07 樊公海、林宗奇的费用待审批通知在 `system_notifications` 中均为 `SENT`，飞书返回了真实 `om_` 消息 ID；13:30 审批后林宗奇的通知也在后台通知中心可查。
- 用户端未看到待办的直接原因是任务列表和审批动作被菜单权限拦截，本轮修复后无需再为每个动态审批人单独配置“项目费用 - 审批”权限。
