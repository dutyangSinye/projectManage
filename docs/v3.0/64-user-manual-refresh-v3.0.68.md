# 64 · 用户手册重编与界面口径文案修正（v3.0.68）

- 日期：2026-09-12
- 范围：重编用户使用手册；同步修正界面上仍停留在旧口径的提示文案
- 文档产物：`docs/01-user-manual-v3.0.68.md`

## 1. 改因

v3.0.56 版手册（`docs/01-user-manual.md`）之后，系统在 v3.0.57 ~ v3.0.68 连续改了 11 个版本，
其中多项是**面向使用者的口径变化**，手册却仍写着旧规则：

| 手册旧描述 | 当前实际 |
|---|---|
| 工时审批通过后按人员单天成本生成项目人员成本 | v3.0.61 起工时不再折算成本，人工成本只认人工成本结转单 |
| 项目预算 = 人天预算、成本预算、费用预算 | v3.0.60 起总预算 = 启用预算项金额合计 |
| 费用添加要选成本大类 / 成本小类 | v3.0.62 起成本分类维度取消，只选预算项 |
| 合同付款走七级审批、出纳末节点确认 | v3.0.61 起改一级费用复核 |
| 系统管理维护“人员成本” | v3.0.68 起该模块整体删除 |
| 基础配置维护预算项模板 | v3.0.65 起模板区下线，预算项只在项目管理里维护 |
| 项目类型是一层下拉 | v3.0.60 起改为项目大类 + 项目小类两级 |

另外，前端有 6 处提示文案没有跟上后端口径，会直接误导使用者。

## 2. 手册改动

新增 `docs/01-user-manual-v3.0.68.md`（旧手册停止维护），结构：

1. 本次版本变更对照表（v3.0.57 → v3.0.68）
2. 系统模块地图、角色速查
3. 登录与工作台
4. 工时管理（含新增的工时填报定时提醒）
5. 项目管理（含项目大类/小类、项目预算项、项目详情 7 个页签）
6. **预算、成本与归集口径**（新增章节，集中解释三句话口径与人员成本变化）
7. 项目合同、合同收款 / 付款
8. 项目费用、人工成本结转、费用复核（新增三章）
9. 项目看板、客户与供应商
10. 系统管理（集成与通知、管理员管理、复核岗位、基础配置）
11. 通知类型一览、关键口径速查、常见问题

截图沿用 `docs/assets/manual-v3.0.56/` 中仍然准确的 12 张；
已失效的人员成本、审批流程、旧费用表单截图不再引用，改为文字描述。

## 3. 界面文案修正（`frontend/src/App.vue`）

| 位置 | 原文案 | 新文案 |
|---|---|---|
| 项目看板“人员成本”卡 | 人员成本 / 已审批工时 × 单价快照 | 人工费用 / 已复核通过的人工成本结转单 |
| 项目详情预算 KPI | 人工费用 / 已审批工时成本 | 人工费用 / 已复核的人工成本结转单 |
| 项目详情“成本组成与预算执行”说明 | 已审批工时、已确认合同付款和已审批项目费用计入实际成本 | 人工成本来自已复核的人工成本结转单，合同成本来自已复核的合同付款，项目费用来自已复核的费用单 |
| 项目预算项弹窗说明 | 已发生金额来自审批通过的工时、合同付款和项目费用 | 已发生金额来自已复核的人工成本结转单、合同付款和项目费用 |
| 合同收款页说明 | 提交后由具备出纳审批权限的人员确认入账 | 提交后由收款复核岗位或具备收付款复核权限的人员确认入账 |
| 合同付款页说明 | 按七级流程流转，出纳末节点确认后计入已付 | 提交后由费用复核岗位一级复核，复核通过后计入项目成本与已付 |
| 基础配置“分类体系”说明 | 项目分类与成本分类改为两级树维护 | 项目分类按两级树维护；成本归集统一使用 8 项预算项，不再单独维护成本分类 |
