# v3.0.60 预算项统一与实现说明

版本：v3.0.60  
日期：2026-09-11  
状态：已发布，已完成本地构建、回归验证和生产健康检查  

## 1. 本次确认口径

研发项目和经营项目统一使用同一套预算项名称：

| 序号 | 预算项 | 默认来源 |
| --- | --- | --- |
| 1 | 人工费用 | 工时审批通过或人工成本结转自动归集 |
| 2 | 材料、设备采购 | 支出合同付款 / 项目费用通用 |
| 3 | 水、电、燃气费用 | 支出合同付款 / 项目费用通用 |
| 4 | 委托、分包、外包费用 | 支出合同付款 / 项目费用通用 |
| 5 | 差旅费用 | 支出合同付款 / 项目费用通用 |
| 6 | 包装、运输费用 | 支出合同付款 / 项目费用通用 |
| 7 | 租赁费、折旧费 | 支出合同付款 / 项目费用通用 |
| 8 | 其他费用 | 支出合同付款 / 项目费用通用 |

项目总预算 = 当前项目启用预算项的预算金额合计。

## 2. 功能实现

### 后台基础配置

- 新增“预算项模板”配置区。
- 经营项目、研发项目各有一套模板配置入口，但默认内容一致。
- 模板支持新增、编辑、删除非内置项、停用内置项。
- 新建项目后，系统按项目类型自动生成项目预算项。

### 项目管理

- 项目新增和编辑不再展示人天预算、项目成本预算和费用预算。
- 项目管理操作栏保留“预算项”按钮。
- 项目预算项弹窗用于维护当前项目各预算项金额、启用状态和备注。

### 合同与费用

- 收入合同不填写预算项和成本分类。
- 支出合同必须选择项目预算项；旧接口未传预算项时，后端自动归集到默认非人工预算项，保证历史导入和旧调用兼容。
- 项目费用必须选择项目预算项；旧接口未传预算项时按费用类型自动选择默认预算项。
- 工时审批通过产生的人员成本统一归集到“人工费用”预算项。

### 看板与详情

- 项目详情和项目看板去掉“人天预算执行”预算口径，只保留“已发生人天”作为工时事实数据。
- 项目详情预算页展示 8 项预算执行：预算金额、已发生、剩余、使用率。
- 项目看板展示总预算、实际总成本、人工费用、合同成本、项目费用、非人工预算使用率。
- 导出项目看板时同步使用新表头。

## 3. 兼容策略

- 数据库旧字段 `budget_days`、`budget_cost`、`expense_budget` 保留，避免破坏历史接口。
- 页面不再把 `budget_days` 当作项目预算控制项。
- 如果旧项目尚无预算项金额，但旧 `budget_cost` 或 `expense_budget` 有值，系统会自动迁移到“其他费用”预算项，避免旧预算数据变 0。
- 旧预算项编码会自动归并到统一 8 项，例如材料和设备采购归并到“材料、设备采购”，外包、分包、委托类归并到“委托、分包、外包费用”。
