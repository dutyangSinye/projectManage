# v3.0.86 合同资金页项目筛选项修复

版本：v3.0.86  
日期：2026-09-24  
状态：已实现

## 1. 问题

合同管理、合同收款、合同付款页面里的“项目”筛选下拉看不到所有项目。排查后发现，这些下拉复用了 `managedProjects`，而 `managedProjects` 是项目管理页的分页结果，会受项目管理当前页码、筛选条件和分页数量影响。

## 2. 修复范围

- 合同管理页面项目筛选下拉。
- 合同收款页面项目筛选下拉。
- 合同付款页面项目筛选下拉。

## 3. 实现说明

前端将合同资金相关列表的项目筛选下拉数据源从 `managedProjects` 改为 `projects`：

- `managedProjects`：项目管理当前页数据，适合项目管理表格；
- `projects`：系统初始化时通过 `/api/v1/projects` 读取的完整项目列表，适合跨模块筛选。

本次不改变后端收款/付款查询接口，不改变角色权限和数据访问范围配置。

## 4. 验证要点

- 合同管理页面项目筛选应显示完整非删除项目列表。
- 合同收款页面项目筛选应显示完整非删除项目列表。
- 合同付款页面项目筛选应显示完整非删除项目列表。
- 项目管理分页或筛选变化不再影响合同资金页面的项目筛选候选项。
