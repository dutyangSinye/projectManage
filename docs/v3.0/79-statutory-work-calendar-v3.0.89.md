# v3.0.89 国家法定工作日历规则设计

日期：2026-09-29  
状态：已确认执行  
适用系统：综合项目管理系统 v3.0.89

## 1. 修改目标

现有工时填报、自动天数计算和填报提醒仅按“周一至周五”为工作日。该规则无法覆盖国家法定节假日和调休，例如：

- 周末被调整为工作日时，应该允许填报、参与天数计算，并发送填报/补填提醒；
- 工作日被调整为法定假日时，不应该要求填报，也不应该发送提醒；
- 跨日期填报时，工时天数应等于日期区间内“国家法定工作日”的数量。

## 2. 规则口径

系统采用“工作日历覆盖优先”的规则：

1. 如果某日期在工作日历中配置为 `WORKDAY`，即使是周六/周日，也按工作日处理。
2. 如果某日期在工作日历中配置为 `HOLIDAY`，即使是周一至周五，也按非工作日处理。
3. 如果某日期没有配置覆盖项，则按默认周一至周五为工作日、周六周日为非工作日处理。
4. 工时开始日期和结束日期仍不允许跨月。
5. 工时天数仍为整数天，且必须等于区间内工作日历计算出的工作日数量。
6. 当天填报提醒和 T-1 补填提醒都使用同一工作日历。

## 3. 本次落地范围

- 新增工作日历数据模型，用于保存法定假日和调休工作日覆盖项。
- 内置 2026 年国务院办公厅公布的节假日与调休上班日作为默认数据。
- 在“系统管理 → 基础配置 → 工作日历”提供维护入口，支持按年份查看、新增/编辑覆盖项、删除自定义覆盖项。
- 后端工时保存、提交、管理员修改统一使用工作日历校验数量。
- 前端新增/编辑工时时，自动按工作日历计算天数。
- 工时填报提醒、T-1 补填提醒改为按工作日历判断是否触发。
- 前端提醒配置文案从“周一至周五”调整为“国家法定工作日”。

## 4. 操作入口

路径：`系统管理 → 基础配置 → 工作日历`

页面能力：

- 按年份查询该年的覆盖项；
- 新增某个日期为“调休工作日”或“法定假日”；
- 编辑日期名称、类型和来源备注；
- 删除自定义覆盖项，删除后该日期回到默认周末规则；
- 内置官方日期不允许删除，但可以编辑类型或名称，避免重启后又被系统自动补回。

## 5. 后续维护

每年国务院办公厅发布下一年度节假日安排后，需要将新的法定假日和调休工作日写入工作日历。未配置的年份仍会回退到默认周一至周五规则。
