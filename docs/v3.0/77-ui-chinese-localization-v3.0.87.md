# v3.0.87 界面英文文案中文化修复

日期：2026-09-24  
状态：已实现，待发布验证

## 背景

合同付款、合同收款等详情页的审批时间线存在直接展示后端枚举值的问题，例如 `CREATE`、`WITHDRAW`、`PENDING_REVIEW`。这类英文码适合用于数据库和接口，不应直接出现在业务用户界面。

## 修改范围

1. 审批时间线事件中文化：
   - `CREATE` → 创建单据
   - `UPDATE` → 修改单据
   - `DELETE` → 删除单据
   - `SUBMIT` → 提交审批
   - `WITHDRAW` → 撤回申请
   - `APPROVE` → 审批通过
   - `REJECT` → 审批驳回
   - `REVERSE` → 冲销
   - `CONFIRM_PAYMENT` → 确认付款
   - `AUTO_APPROVE` → 系统自动通过

2. 状态中文化补齐：
   - `PENDING_REVIEW` → 待复核
   - `APPROVED_PENDING_PAYMENT` → 待支付
   - `PAID` → 已支付
   - `REVERSED` → 已冲销

3. 页面标题和辅助标识中文化：
   - 工作台、我的工时、工时审批、工时看板、项目管理、项目合同、合同收款、合同付款、项目费用、费用复核、客户/供应商、权限管理、集成与通知、基础配置等页面顶部英文标识统一替换为中文。

4. 附件和导入说明中文化：
   - Word/Excel/PPT 类型展示改为“文档/表格/演示文稿”；
   - 导入说明改为“电子表格”和“逗号分隔文本”。

5. 权限动作和接口错误中文化：
   - 前端权限动作补齐“修改、导入、上传、下载、重试”等中文标签；
   - 后端权限动作白名单补齐 `IMPORT/UPLOAD/DOWNLOAD/RETRY/UPDATE`，避免菜单已有动作保存时被判定为非法；
   - 前端统一接口错误出口增加常见错误码中文翻译，减少用户界面直接出现英文错误码。

## 不改变的内容

- 数据库、接口和后端业务枚举值仍然使用英文码；
- 审批、合同、收付款、费用、工时的业务状态流转不变；
- 飞书通知收件人和深链规则不变。

## 验收点

- 合同付款详情审批时间线不再显示 `CREATE/WITHDRAW/PENDING_REVIEW`；
- 权限管理、生效权限、通知中心、项目/合同/收付款/费用详情页面不出现明显英文业务枚举；
- 常见后端错误码在页面提示中显示为中文；
- 前端构建和后端回归测试通过。
