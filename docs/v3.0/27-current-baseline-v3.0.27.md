# 综合项目管理系统当前文档基线

> 文档版本：v3.0.27 ｜ 日期：2026-09-02 ｜ 对应生产运行版本：v3.0.26 ｜ 状态：已同步

## 1. 基线说明

本文档是当前生产系统的统一文档入口，整合 v3.0.4 至 v3.0.26 的已落地功能和规则。生产容器当前版本仍为 `v3.0.26`；`v3.0.27` 是本次文档同步基线，不代表新增业务代码。

历史版本文档继续保留，作用是记录当时的需求、设计和验证过程。阅读当前实现时，以本文档、`01-prd.md`、`02-product-design.md`、`03-system-design.md`、用户手册和 `07-change-log.md` 为准。

## 2. 当前产品范围

系统名称统一为“综合项目管理系统”，一级模块为：

1. 工作台：按角色展示项目负责人工作区和员工工作区，提供填报工时、工时审批、发起合同收款和发起合同付款入口。
2. 工时管理：我的工时、工时审批、工时看板和受权限控制的工时台账。
3. 项目管理：项目管理、项目合同、合同收款、合同付款、项目看板、供应商管理和客户管理。
4. 系统管理：人员成本、集成与通知、管理员管理和基础配置。

## 4. 关键业务口径

- 工时数量按“天”统计，不展示或计算小时。
- 同一人员同一天无论项目是否不同，都只能填报一次；已有日期区间与新日期区间相交时禁止提交。
- 工时审批通过才计入项目已发生人天和人员成本；驳回、草稿、审批中的工时不计入。
- 人员成本使用审批通过时的人员单天成本快照；当前版本暂不维护成本生效日期。
- 应收只统计已到期收入阶段金额减去该阶段已确认收款。
- 应付只统计已到期支出阶段金额减去该阶段已确认付款。
- 已收/已付只统计审批通过且未冲销的合同收付款单。
- 项目总成本 = 已审批工时人员成本 + 已确认外部付款成本。
- 项目毛利 = 已收 - 项目总成本；毛利率在已收大于零时计算。
- 合同收付款单由具备出纳审批权限的人员处理，审批结果通知申请人；通知中的审批人使用实际操作人姓名。

## 5. 权限与数据范围

权限校验同时发生在菜单、按钮、接口和数据查询层。业务按钮按操作权限控制，查询、重置、分页、TAB 切换、展开收起、关闭和返回等通用界面动作不单独配置。

项目数据范围支持“本人负责项目”“指定部门及下级部门”“全部项目”。没有“全部项目”权限时，接口不会因前端参数而返回全量项目。部门选择上级部门时包含其所有下级部门。

## 6. 提醒目录

系统提醒和飞书提醒统一来源于以下事项：

- 合同收入阶段或支出阶段未来 30 天内到期。
- 合同阶段到期未收或未付，标记为逾期并按策略重复提醒。
- 成本预算接近或超过阈值。
- 人天预算接近或超过阈值。
- 待审批工时、待审批合同收款单和待审批合同付款单。
- 合同收款单或合同付款单审批通过/驳回。
- 组织同步失败、通知发送失败和待重试通知。

工作台提醒列表展示未来 30 天内阶段事项；通知策略由系统管理中的统一编辑弹窗保存，实际发送结果进入通知中心。

## 7. 附件、时间和部署

- 合同、合同收款单和合同付款单在新建表单中即可选择附件，业务实体保存后自动完成关联。
- 附件支持列表、预览、下载和删除；Office 预览失败时保留原文件下载兜底，不承诺复杂版式完全还原。
- 所有时间生成和展示使用 `Asia/Shanghai`。NAS Docker Compose 需设置 `TZ: Asia/Shanghai`；不能只依赖容器时区，后端不得继续使用 `datetime.utcnow()` 作为业务时间源。
- 线上地址为 `http://192.168.112.188:8088`。生产数据库、附件目录和环境密钥不包含在文档包中。

## 8. 当前边界

- 当前审批是系统本地审批任务，飞书负责免登和应用消息通知，不创建真实飞书审批实例，也不依赖审批回调。
- 系统不替代财务总账、银行转账、发票、税务、工资和报销系统。
- 人员成本生效日期、复杂多级审批、多币种和节假日日历不在当前基线内。

## 9. 文档维护规则

新增功能或业务规则先更新当前基线和对应设计文档，再修改代码。小功能使用小版本号；仅在整体 UI 或核心模块大规模升级时升主版本。历史版本只追加变更索引，不回写正文。本次用户手册详细化属于文档版本 `v3.0.28`，生产代码仍为 `v3.0.26`。
